# BNF 25일선 이격도 백테스트

코스피·코스닥 종목이 25일 이동평균선보다 크게 떨어졌을 때(이격도가 낮을 때) 사면 평균 회귀로 돈을 버는지 확인한다.
일본 개인 투자자 BNF 가 썼다고 알려진 방법이다.

확인하는 것은 세 가지다.

1. 이격도 기준값(95 → 70)에 따라 반등 확률과 평균 수익이 어떻게 달라지나
2. 보유 기간, 25일선 회복, 손절폭 가운데 어떤 청산 규칙이 거래당 기대값을 가장 높이나
3. 지수가 120일선 위일 때만 사거나(상승장 필터), 지수도 같이 급락한 날만 사면(동반급락 필터) 나아지나

결과는 [`results/report.md`](results/report.md) 에 나온다. `results/` 는 저장소에 올리지 않으므로 직접 돌려야 한다.

## 데이터

데이터 수집, 거르는 규칙, 매매·포트폴리오 계산은 엔진 저장소 [krx_backtest_core](https://github.com/destory1984/krx_backtest_core)(`krxbt`)에 있다.
이 저장소에는 이격도 규칙, 그리드, 보고서만 있다. 시세는 저장소 밖 `../../krx_data` 폴더에 두고 다른 알고리즘과 같이 쓴다.

| 무엇 | 어디서 |
|---|---|
| 일봉 시세(수정주가), 지수 | 네이버 차트 API `api.finance.naver.com/siseJson.naver` |
| 지금 상장된 종목 목록 | FinanceDataReader `StockListing("KRX")` |
| 2008년 이후 상장폐지 종목 | KRX KIND 상장폐지현황 (`kind.krx.co.kr`) |
| 월별 상장 종목 목록 (선택) | pykrx. KRX 로그인이 있을 때만 |

설계서는 pykrx 를 주 데이터로 잡았지만, 2025년 말부터 KRX 정보데이터시스템이 로그인을 요구해서 pykrx 의 KRX 경로는 `KRX_ID` / `KRX_PW` 환경변수 없이 빈 값만 준다.
그래서 시세는 로그인이 필요 없는 네이버에서 받는다. 네이버 시세는 액면분할·무상증자를 반영한 수정주가이고, 상장폐지된 종목도 내려준다.
FinanceDataReader 가 쓰는 네이버 주소는 최근 3,000 거래일(약 12년)까지만 주기 때문에, 기간을 지정할 수 있는 `siseJson` 주소를 직접 부른다.

상장폐지 종목을 빼면 살아남은 종목만 보게 되어 결과가 좋게 나온다(생존편향). 이를 막으려고 KIND 에서 2008년 이후 코스피·코스닥 상장폐지 종목 936개를 받아 넣는다.
네이버는 상장폐지 종목 시세를 2008년 무렵부터만 준다. 2005 → 2007년에 폐지된 종목은 시세가 없어서 기간을 2008년부터로 잡았다.
`KRX_ID` / `KRX_PW` 환경변수가 있으면 대신 pykrx 로 시작 월부터 매달 첫 거래일의 상장 목록을 모은다.

빼는 종목과 구간:

- 우선주(종목코드 끝자리가 0 이 아님), 스팩, 리츠, 선박투자회사("○○9호"). ETF·ETN 은 주식 목록에 원래 없다.
- 상장 후 25거래일이 안 된 구간 (25일선이 없다)
- 거래량 0 인 날(거래정지)
- 20일 평균 거래대금 10억 원 미만. 거래대금은 종가 × 거래량으로 어림한다(네이버 시세에 거래대금이 없다).
- 상장폐지 종목의 마지막 7거래일(정리매매). 가격 제한이 없어 하루 -50% 도 나오는데, 정리매매는 그때 이미 공시된 사실이라 빼도 미래 정보를 쓰는 게 아니다.
- 시세가 끊긴 날부터 25거래일. 네이버가 액면분할·감자를 반영하지 못한 종목이 가끔 있다. 가격 제한(2015-06-15 전 ±15%, 이후 ±30%)을 넘게 움직인 날과 3거래일 넘는 거래정지가 풀린 날을 끊김으로 본다.
- 끊긴 날을 끼고 들고 있던 거래(재개일에 반 토막 이하·두 배 이상, 또는 가격 제한 초과)는 결과에서 뺀다. 2008년 이후 312개 종목, 조합당 60건쯤이다.

## 매매 규칙

- 신호: 종가 기준 이격도(종가 ÷ 25일선 × 100) ≤ 기준값
- 진입: 신호 다음 거래일 시가. 그날 거래정지면 신호를 버린다.
- 청산(먼저 오는 것):
  1. 종가가 25일선 이상 → 다음 거래일 시가
  2. 시가가 손절가 아래 → 시가, 장중 저가가 손절가 이하 → 손절가
  3. 최대 보유일 도달 → 그날 종가. 보유일은 진입일을 1일째로 센다. 거래정지일도 세지만 그날은 팔지 않고 다음 거래일 종가에 판다.
  4. 데이터가 끝남(상장폐지, 긴 거래정지) → 마지막 거래일 종가, `forced`
- 같은 종목을 들고 있는 동안의 신호는 무시한다.
- 비용: 수수료 매수·매도 각 0.015%, 슬리피지 편도 0.1%, 매도세는 매도일 기준 그해 세율(2019-05 전 0.30%, 0.25%, 2021 0.23%, 2023 0.20%, 2024 0.18%, 2025 0.15%, 2026 0.20%). 코스피(거래세+농특세)와 코스닥 합계가 해마다 같다.

모든 값은 `config.yaml` 에서 바꾼다. 신호일 종가 매수, 25일선 회복일 종가 청산도 옵션으로 있다.

## 파라미터 그리드

이격도 기준 6개(95, 90, 85, 80, 75, 70) × 손절 4개(없음, -5%, -8%, -12%) × 최대 보유일 4개(3, 5, 10, 20) × 시장 필터 5개(없음, 상승장만, 동반급락 95·97·99) × 시장 3개(코스피, 코스닥, 합산) = 1,440개 조합.
시장은 같은 거래를 나눠 보는 것이라 시뮬레이션은 종목마다 480번 돈다. 거래 한 건씩 도는 반복문은 numba 로 컴파일하고, 종목은 6개 프로세스에 나눠 돌린다.

## 결과 요약 (2008-01 → 2026-09, 3,243개 종목, 비용 포함)

- 이격도가 낮을수록 거래당 기대값이 높다. 합산·손절 없음·시장 필터 없음·20일 보유 기준으로 ≤95 는 -0.23%, ≤85 는 +1.7%, ≤70 은 +6.4% 다.
- 지수 120일선 필터(상승장만)는 비교한 216쌍 중 한 쌍도 낫지 않았다. 폭락장 매수를 막아 버린다.
- 지수도 같이 빠진 날만 사는 동반급락 필터(신호일 지수 이격도 ≤ 95, 97, 99)는 세 기준 모두 216쌍 전부에서 나았다.
  코스피 평균 기대값은 필터 없음 +2.2%, ≤99 +3.1%, ≤97 +3.7%, ≤95 +4.5% 다.
- 1등 조합은 코스피 / 이격도 ≤70 / 손절 없음 / 20일 / 동반급락 ≤95 로, 거래 804건에 거래당 +19.8%, 승률 80% 다.
  폭락 구간 6개(2008-10, 2011-08, 2020-03, 2022, 2024-08, 2026-06 → 08)를 빼도 거래당 +14.4% 다.
- 2008 → 2016 과 2017 → 2026 의 조합 순위 상관은 0.90 이다.
- 1억·5종목 포트폴리오. 코스피 / 이격도 ≤70 / 손절 -8% / 20일 보유 조합을 시장 필터와 재진입 제한만 바꿔 돌렸다.
  포트폴리오는 신호마다 따로 거래를 만들고, 실제로 그 종목을 들고 있을 때만 신호를 버린다(설계서 4.1).
  재진입 제한은 손절로 판 종목을 정한 거래일 수만큼 다시 사지 않는 규칙이다. 값은 연환산 / 최대 낙폭이다.

  | 시장 필터 | 제한 없음 | 20거래일 | 60거래일 | 120거래일 |
  |---|---|---|---|---|
  | 없음 | -1.6% / -81% | +5.0% / -54% | +4.5% / -56% | +8.1% / -44% |
  | 상승장만 | -9.4% / -86% | -4.3% / -65% | -4.4% / -70% | -2.8% / -60% |
  | 동반급락 ≤95 | +9.9% / -45% | +6.6% / -39% | +7.6% / -39% | +7.2% / -38% |
  | 동반급락 ≤97 | +6.0% / -65% | +9.4% / -51% | +7.5% / -42% | +8.6% / -39% |
  | 동반급락 ≤99 | +5.6% / -71% | +7.6% / -50% | +6.0% / -43% | +5.5% / -43% |
  | 코스피 지수 보유 | +7.4% / -50% | | | |

  - 재진입 제한은 15칸 모두에서 최대 낙폭을 줄였다(-81% → -44% 등). 연환산은 조합마다 오르기도 내리기도 해서 일정하지 않다.
  - 동반급락 ≤95 는 제한 없이도 연 +9.9%, 최대 낙폭 -45% 로 지수 보유(+7.4%, -50%)보다 나았고, 2008 → 2016 +10.3%, 2017년부터 +9.6% 로 두 기간이 비슷했다.
  - 규칙을 조금만 바꿔도 연환산이 3 → 4%p 씩 움직인다. 11년 넘게 돌려도 실제로 산 거래가 250 → 600건이고 폭락 몇 번에 결과가 갈리기 때문이다. 한 칸의 숫자보다 표 전체의 방향을 보는 게 맞다.
- 2008 → 2009년에는 지수가 몇 달 동안 25일선 아래에 머물렀다. 그동안 구조조정에 들어간 건설·조선주가 계속 신호를 냈고,
  재진입 제한이 없으면 같은 종목을 네다섯 번씩 다시 사서 -8% 손절을 거듭했다. 재진입 제한이 낙폭을 줄이는 이유다.
- 폭락일에 자리 늘리기. 같은 조합에서 평소 5자리, 신호일 지수 이격도 ≤95 인 날은 10·20·40자리까지 사게 했다.
  폭락일 신호 하나에는 평가금액의 1/10·1/20·1/40 을 넣는다. 재진입 제한 없음 기준, 연환산 / 최대 낙폭:

  | 시장 필터 | 5자리 | 5→10 | 5→20 | 5→40 | 늘 20자리 |
  |---|---|---|---|---|---|
  | 없음 | -1.6% / -81% | +3.1% / -73% | +3.7% / -74% | +1.0% / -75% | +8.5% / -45% |
  | 동반급락 ≤95 | +9.9% / -45% | +9.9% / -44% | +10.0% / -39% | +7.2% / -33% |  |
  | 동반급락 ≤97 | +6.0% / -65% | +7.8% / -54% | +7.8% / -40% | +5.1% / -36% | +8.0% / -39% |
  | 동반급락 ≤99 | +5.6% / -71% | +8.7% / -56% | +9.0% / -44% | +6.2% / -38% | +9.1% / -39% |

  - 자리를 늘리면 최대 낙폭은 거의 모든 칸에서 줄었다(≤95: -45% → -39%). 연환산은 20자리까지 조금 오르거나 그대로고, 40자리에서는 떨어졌다.
  - 동반급락 ≤95 에서 5→20자리로 늘리면 산 거래는 249건에서 589건, 거래당 평균은 +5.3% 에서 +7.7% 로 올랐다.
    그런데 자리 하나에 넣는 돈이 20% 에서 5% 로 줄어, 주식을 들고 있는 날의 주식 비중이 평균 56% 에서 29% 로 떨어졌다. 40자리는 19% 다.
    폭락 때 신호가 20 → 40개씩 한꺼번에 나지 않으면 자리가 비고 돈이 현금으로 논다. 좋은 거래를 더 잡은 만큼 돈을 덜 걸어서 연환산이 제자리다.
  - 그러니 자리 수만 늘리는 것으로는 부족하다. 폭락일에 현금을 그날 신호 수로 나눠 다 넣는 식으로 거는 돈을 늘려야 효과를 볼 수 있다(아직 안 해 봤다).

## 쉬는 돈을 지수에 넣어 두기 (`python -m src.park`, `--us`)

동반급락 ≤95 포트폴리오도 종목을 들고 있는 날은 16% 뿐이라(한국), 나머지 날 노는 현금을 지수에 넣어 두면 어떻게 되는지 본다.
방식: 노는 현금은 그날 지수 종가에 지수를 사서 넣어 두고, 종목을 살 때 현금이 모자라면 그만큼 그날 지수 시가에 지수를 판다.
종목을 팔면 받은 돈으로 그날 지수 종가에 다시 지수를 산다. 재진입 제한은 없음(0일) 기준이다.

지수 대기와 코스피·나스닥100 보유 줄은 배당이 빠진 가격 지수로 계산해서, 지수를 실제로 들고 있었다면 붙었을 배당(연 1.5 → 2%쯤)이 빠져 있다. 현금 대기 줄은 애초에 지수를 들지 않으니 이 배당과 상관없다.
미국은 이번에 133종목으로 돌렸다. ibs 작업에서 SPY·QQQ·IWM·DIA 를 추가하고 시세를 새로 받았지만, 예전 129종목 표(위 「미국 주식」 절)와 현금 대기 쪽 연환산·MDD·체결 거래 수는 모두 같다.
달라진 것은 주식+ETF 줄의 trades_available(후보 거래 수)뿐이다: 필터없음 573 → 575, 동반급락 ≤97 468 → 470, ≤99 516 → 518 로 2건씩 늘었다.
한국은 동반급락 ≤95 필터에서 지수 대기가 연 +16.1%(MDD -50%)로 코스피 보유(+7.4%, -50%)를 앞선다. 다만 필터를 걸지 않으면 지수 대기(+2.8%, -81%)가 코스피 보유에 못 미친다.
미국은 가장 나은 조합(주식+ETF, 동반급락 ≤99)이 연 +21.1%로 나스닥100 보유(+15.5%)보다 연환산은 높지만(133종목이 지금 나스닥100·다우30에 든 종목 위주라 생존편향이 있다는 점은 아래 「미국 주식」 절과 같다), MDD는 -57%로 나스닥100 보유(-50%)보다 크다.
지수 대기의 MDD는 지수 보유(-50%)에 가까운 경우도, 더 나쁜 경우도 있다. 한국은 동반급락 ≤95(-50%)만 지수 보유와 같고, 필터없음·상승장만은 -81%, ≤97 -64%, ≤99 -73% 로 더 크다.
미국은 6줄 모두 -57% 로 나스닥100 보유(-50%)보다 크다.
동반급락 ≤95 조합은 학습기(→ 2016) 연 +8.0%, 검증기(2017년부터) 연 +24.2% 로(현금 대기는 +10.3% / +9.6%), 지수 대기 쪽이 검증기에 크게 몰려 있다.
코스피 지수 자체도 학습기 +1.0%, 검증기 +13.7% 로 뛰어서(`results/park.csv` 의 KOSPI 보유 줄), 지수 대기 줄의 학습·검증 격차 대부분은 지수 쪽에서 온다.
신호가 몰린 날 지수를 팔아도 살 돈이 모자라면 그 신호는 버려진다. 필터없음은 체결 거래가 1138건에서 1136건으로, 동반급락 ≤99 는 622건에서 621건으로 줄었다.

## 걸어가며 검증 (`python -m src.walkforward`, `--us`)

2011년부터 해마다, 그 해 전까지의 거래만 보고 기대값 1등 조합을 고른다(한국 거래 200건·미국 100건 이상). 그 조합을 다음 한 해 동안 쓴다.
학습 기간은 2008년부터 늘어난다. 결과는 `results/walkforward.md`, `results/us/walkforward.md`.

| | 한국 | 미국 |
|---|---|---|
| 고른 조합 | 16해 중 15해가 코스피 ≤70 / 손절 없음 / 동반급락 ≤95 (보유 10일 → 2021년부터 20일) | ≤75 → 2023년부터 ≤70, 동반급락 필터가 대부분 |
| 고른 조합의 검증 거래 평균 | +18.3% (470건) | +7.0% (164건) |
| 그 해 모든 조합 중앙값을 넘은 해 | 거래가 있던 12해 중 10해 | 12해 중 10해 |
| 학습·검증 순위 상관 평균 | 0.66 | 0.49 |
| 신호가 한 건도 없던 해 | 4해 (2014, 2016, 2017, 2025) | 4해 |
| 포트폴리오 2011년부터 (걸어가며 고른 조합) | +8.0% / MDD -29% | +7.5% / -40% |
| 같은 기간, 전체 기간 1등 조합 (뒤늦게 앎) | +9.6% / -29% | +6.7% / -38% |
| 같은 기간, 지수 보유 | 코스피 +8.1% / -44% | 나스닥100 +18.0% / -36% |

- 미래를 모른 채 골라도 한국은 2011년부터 거의 같은 조합을 골랐고, 검증 해 거래도 대부분 플러스였다. 뒤늦게 고른 1등 조합과 차이가 연 1.6%p 다.
  조합 고르기가 운이었던 것은 아니라는 뜻이다.
- 다만 신호가 폭락 때만 나서 해마다 거래가 0 → 60건(2020년만 278건)이다. 거래가 1 → 5건인 해는 기대값이 크게 흔들린다.
- 한국 포트폴리오는 코스피와 연환산은 같고 최대 낙폭이 15%p 작았다. 미국은 나스닥100 보유에 한참 못 미친다.

## 미국 주식 (`python -m src.us`)

같은 그리드를 미국 129종목(나스닥100 + 다우30 + 관심 종목, ETF 3개 포함)에 돌렸다. 데이터는 야후, 가격은 배당 반영, 시장 필터 지수는 나스닥100,
비용은 수수료 편도 0.07% + 슬리피지 편도 0.05%. 결과는 `results/us/report.md`.
**지금 지수에 든 종목만 있어서 생존편향이 크다.** 그동안 빠지거나 망한 종목의 급락이 빠져 있어 기대값이 실제보다 높게 나온다.

- 거래당 기대값은 한국과 같은 방향이다. 주식만, 손절 없음, 20일 보유 기준으로 ≤95 +1.4%, ≤85 +3.2%, ≤70 +12.4% 이고, 동반급락 필터를 걸면 조금씩 더 높다.
  상승장만 필터는 여기서도 모든 칸에서 더 나빴다.
- 그런데 대형주라 이격도 70 아래로 떨어지는 일이 드물다. ≤70 신호는 18년 동안 123건뿐이다.
- 5종목 포트폴리오로 돌리면 주식을 들고 있는 날이 10% → 17% 뿐이어서 연 +5.5% → 6.8%, 최대 낙폭 -32% → -38% 다.
  나스닥100 지수 보유(배당 빼고 연 +15.5%, -50%)에 크게 못 미치고 S&P500(+9.4%, -53%)에도 못 미친다.
- 미국 대형주에서는 이 규칙만으로 돈을 거의 놀리게 된다. 기다리는 동안 지수를 들고 있다가 신호가 나면 옮겨 타는 방식을 시험한 결과는 위 「쉬는 돈을 지수에 넣어 두기」 절에 있다.

## 덤: RSI 다이버전스 (일봉, `src/divergence.py`)

같은 데이터(3,243종목, 2008 → 2026 일봉)로 RSI 다이버전스를 시험했다. 정의는 다른 프로젝트(koreainvest `kis_diverge.py`, 5분봉)의 것을 그대로 옮겼고,
삼성전자 등 5종목에서 원래 코드와 찾은 다이버전스 808개가 모두 같았다.
신호는 저점 뒤 3일째(확인일)에 나고 다음 날 시가에 산다. 초과 = 같은 날 산 모든 종목 평균보다 얼마나 나았나.

| 신호 (손절 없음) | 거래 | 5일 초과 | 20일 초과 (90% 구간) |
|---|---|---|---|
| 상승 보통 | 31,255 | -0.02% | -0.17% (-0.33 → +0.01) |
| 상승 보통 + MACD(이중) | 22,791 | -0.03% | -0.30% (-0.50 → -0.10) |
| 상승 히든 | 46,229 | -0.15% | -0.33% (-0.48 → -0.16) |
| 상승 보통 + 동반급락≤97 | 6,888 | -0.36% | -0.69% (-1.14 → -0.29) |
| 하락 히든 (사면) | 41,812 | +0.15% | +0.25% (+0.11 → +0.39) |
| 상승 보통, 저점 날 종가에 샀다면 | 31,312 | +2.09% | +1.95% |
| 상승 히든, 저점 날 종가에 샀다면 | 46,082 | +4.20% | +3.80% |

- 매수 쪽 다이버전스는 어느 것도 평균보다 낫지 않았다. 동반급락 날 다이버전스로 고르면 오히려 다른 급락 종목보다 못했다.
- 저점 날 종가에 샀다면 +2% → 4% 앞섰다. 그러나 그날이 저점인 줄은 3일 뒤에야 안다. 그 3일 동안 되돌림이 다 지나간다. 5분봉에서 본 것과 같은 결론이다.
- 하락 히든 뒤에 사면 +0.15% → 0.25% 앞섰지만(거꾸로 된 방향), 왕복 비용 0.4% 에 못 미친다.

## 돌리는 법

```
pip install -r requirements.txt   # 엔진 krxbt v0.2.1 을 깃허브에서 받는다. 엔진을 같이 고칠 땐 pip install -e ../krx_backtest_core
python -m krxbt.fetch      # 시세 수집 → ../../krx_data. 처음엔 약 35분(3,243개, 요청 사이 0.3초). 다시 돌리면 새 날짜만 받는다
python -m src.grid         # 1,440개 조합 시뮬레이션과 요약
python -m src.checks       # 검증 체크리스트
python -m src.portfolio    # 상위 5개 조합 포트폴리오
python -m src.report       # 히트맵과 report.md
python -m src.park         # 쉬는 돈을 지수에 (--us 는 미국)
```

한 종목만 들여다볼 때:

```
python -m src.simulate 005930 85 -0.08 10 crash97   # 종목, 이격도 기준, 손절(none 가능), 최대 보유일, 시장 필터
```

## 파일

```
config.yaml          모든 파라미터 (data·universe·rules·costs 는 엔진이 읽는다)
src/common.py        설정 읽기, results/ 경로
src/simulate.py      이격도 규칙: 신호(이격도 ≤ 기준값 + 시장 필터), 익절(종가 ≥ 25일선). 계산은 krxbt.engine
src/grid.py          파라미터 그리드, grid_summary.csv
src/checks.py        검증 체크리스트, 단순 반복문으로 다시 계산해 대조
src/portfolio.py     1억 원, 최대 5종목 포트폴리오 (계산은 krxbt.portfolio)
src/divergence.py    덤: RSI 다이버전스 일봉 시험
src/report.py        히트맵, report.md
results/             trades.parquet, grid_summary.csv, heatmap_*.png, report.md
```

차트는 한국식으로 이익은 빨강, 손실은 파랑이다.
