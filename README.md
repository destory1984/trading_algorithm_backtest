# trading_algorithm_backtest

한국·미국 주식의 단기 매매 규칙을 일봉으로 백테스트한 모음이다. 알고리즘 하나에 폴더 하나를 두고, 폴더마다 지시서(`SPEC.md`), 설정(`config.yaml`), 코드, 결과 설명(`README.md`), 판단 기록(`NOTES.md`)이 있다.
주문 코드와 증권사 API 연결은 없다. 결과 파일(`results/`)은 저장소에 올리지 않으므로 폴더마다 직접 돌려야 한다.

## 공통 조건

- 시세는 저장소 밖에 두고 모든 폴더가 같이 쓴다. 한국은 `../krx_data`(네이버 차트), 미국은 `../us_data`(야후, 배당 반영 가격)다.
- 비용은 한국 수수료 편도 0.015% + 슬리피지 0.1% + 그해 매도세, 미국 수수료 편도 0.07% + 슬리피지 0.05% 다.
- 규칙과 판단 기준은 돌리기 전에 지시서에 고정하고, 결과를 본 뒤 바꾸지 않는다. 바꾸고 싶어지면 새 지시서를 쓴다.
- 비교 기준은 단순 보유만이 아니다. 최대 낙폭을 전략과 같게 맞춘 보유(비중 w + 현금)와 노출을 맞춘 보유를 같이 본다. 현금으로 쉬는 날이 많은 전략은 단순 보유와 비교하면 불리하고, 비중 0% 와 비교하면 유리하기 때문이다.

## 지금까지 배운 것

1. **미국 ETF 단기 전략은 비용에 진다.** 편도 0.12% 를 한 해 30번 안팎 물면 연 7%p 가 빠진다. IBS 는 비용이 0 이면 선별 구간에서 4개 ETF 모두 낙폭을 맞춘 보유를 이기지만, 편도 12bp 에서는 2개만 이긴다. 거래가 매일인 밤사이 보유(S9)는 비용 없이 연 +6.2% → +10.6% 인데 비용을 넣으면 연 -40% 안팎이다.
2. **반등 효과 자체는 있다.** IBS 는 같은 수의 무작위 거래 2,000번보다 손익비가 높다(1.27 → 1.37, 무작위 중앙값 0.84 → 0.92). 효과는 지수가 200일선 아래일 때 몰린다(거래당 +0.34 → +0.74%, 위에서는 -0.06 → +0.11%). ibs_lev_backtest 와 us_shortterm 이 따로 같은 모양을 봤다. 이 가설을 만들지 않은 ETF 6개(ibs_bear_backtest)에서는 방향은 같았지만(5/6) 크기가 작았고(아래 구간 t 1.7 이하), 같은 낙폭의 보유를 이긴 종목은 1개였다. 가설을 만든 종목에서만 좋게 나온다.
3. **상승장 필터(지수가 이평선 위일 때만 산다)는 평균회귀에 해롭다.** bnf 는 비교한 216쌍 중 한 쌍도 낫지 않았다. 폭락 때 사는 기회를 막기 때문이다.
4. **쉬는 돈을 지수에 넣어 두는 것은 경우에 따라 다르다.** bnf 코스피 동반급락 ≤95 는 연 +9.9% → +16.1% 가 됐지만, 오른 몫 대부분은 2017년부터 코스피 자체가 오른 데서 왔다(코스피 학습기 연 +1.0%, 검증기 +13.7%). IBS 에서는 같은 평균 비중의 지수 고정 보유를 이긴 경우가 없다.
5. **2023 → 2026 은 IBS·RSI(2) 에게 깨끗한 표본 밖이 아니다.** 앞선 폴더들이 이미 그 구간까지 돌렸다. 앞으로 새 규칙은 처음부터 봉인할 구간을 정하고 시작한다.
6. **거래 단위로 강한 규칙이 계좌로는 약할 수 있다.** bnf 동반급락은 거래당 +19.8% 인데, 신호가 폭락 며칠에 몰려(이익의 65% 가 신호일 5일) 자리 5개로는 대부분을 놓친다. 같은 폭락일에 아무 종목을 사도 거래당 +16.4% 라서 수익 대부분은 "폭락한 날 산다"에서 온다.
7. **거래 단위 Deflated Sharpe 는 거래가 같은 날에 몰리면 너무 후하다.** bnf 는 거래 804건으로 보면 1.00, 신호일 119개로 보면 0.53 이다. 다음 지시서부터는 신호일 단위로 잰다.
8. **지수 타이밍은 "덜 들고 있기"보다는 낫지만 공짜가 아니다.** 미국 SPY 에서 200일선, 10개월선, 변동성 목표 모두 같은 낙폭의 고정 비중보다 연 2.3 → 3.6%p 더 벌었다. 그러나 보유보다 1.4 → 3.5%p 덜 벌었고, 한국은 2026-06 → 08 급락을 추세 규칙이 피하지 못했다.

## 시행 수

과최적화 점검(Deflated Sharpe)에 쓰는 누적 시행 수는 미국 **1,216**(ibs_backtest 768, ibs_lev_backtest 48, rsi2_backtest 216, us_shortterm 1차 72, us_shortterm 2차 이웃 문턱값 100, ibs_bear_backtest 12), 한국 **1,526**(bnf 그리드 1,440, 포트폴리오 변형 86) 이다. bnf 심화의 이웃 18칸은 그리드 안이라 더하지 않았다. index_timing_backtest 18개는 목표가 달라(같은 수익에 낮은 낙폭) 따로 센다.

## 다음 후보

IBS 는 네 번(ibs_backtest, ibs_lev_backtest, us_shortterm, ibs_bear_backtest) 떨어져 멈춘다. 남은 것은 둘이다.

1. **폭락일에 돈을 다 거는 bnf 포트폴리오.** 거래 단위 수익은 강한데 자리 5개가 병목이다. 다만 폭락일과 그 반등을 모두 이미 본 데이터라 좋게 나와도 믿기 어렵고, 낙폭도 커질 수 있다.
2. **실제 수수료 확인.** 해외주식 수수료가 편도 0.07% 보다 낮은 계좌라면 비용의 벽이 낮아진다.

목표를 "지수 수익은 그대로 두고 낙폭만 줄이기"로 바꿔 [index_timing_backtest](index_timing_backtest) 에서 알려진 규칙 3개를 판정했다. 6개 모두 탈락했지만, 미국에서는 세 규칙 모두 같은 낙폭의 고정 비중보다 연 2.3 → 3.6%p 더 벌었다. 낙폭을 줄이는 값으로 수익을 얼마나 내줄지는 기준이 아니라 사용자가 정할 문제다. 그 전의 메모: 지금까지 결과로는 일봉 단기 규칙으로 지수 보유를 이기기 어렵다. "지수 수익은 그대로 두고 낙폭만 줄이기"라면 bnf 걸어가며 검증(코스피와 연 수익 같고 낙폭 15%p 작음)이 출발점이 될 수 있다.
