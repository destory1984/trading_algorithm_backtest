# BNF 25일선 이격도 백테스트

코스피·코스닥 종목이 25일 이동평균선보다 크게 떨어졌을 때(이격도가 낮을 때) 사면 평균 회귀로 돈을 버는지 확인한다.
일본 개인 투자자 BNF 가 썼다고 알려진 방법이다.

확인하는 것은 세 가지다.

1. 이격도 기준값(95 ~ 70)에 따라 반등 확률과 평균 수익이 어떻게 달라지나
2. 보유 기간, 25일선 회복, 손절폭 가운데 어떤 청산 규칙이 거래당 기대값을 가장 높이나
3. 지수가 120일선 위일 때만 사거나(상승장 필터), 지수도 같이 급락한 날만 사면(동반급락 필터) 나아지나

결과는 [`results/report.md`](results/report.md) 에 나온다. `results/` 는 저장소에 올리지 않으므로 직접 돌려야 한다.

## 데이터

| 무엇 | 어디서 |
|---|---|
| 일봉 시세(수정주가), 지수 | 네이버 차트 API `api.finance.naver.com/siseJson.naver` |
| 지금 상장된 종목 목록 | FinanceDataReader `StockListing("KRX")` |
| 2008년 이후 상장폐지 종목 | KRX KIND 상장폐지현황 (`kind.krx.co.kr`) |
| 월별 상장 종목 목록 (선택) | pykrx. KRX 로그인이 있을 때만 |

설계서는 pykrx 를 주 데이터로 잡았지만, 2025년 말부터 KRX 정보데이터시스템이 로그인을 요구해서 pykrx 의 KRX 경로는 `KRX_ID` / `KRX_PW` 환경변수 없이 빈 값만 준다.
그래서 시세는 로그인이 필요 없는 네이버에서 받는다. 네이버 시세는 액면분할·무상증자를 반영한 수정주가이고, 상장폐지된 종목도 내려준다.
FinanceDataReader 가 쓰는 네이버 주소는 최근 3,000 거래일(약 12년)까지만 주기 때문에, 기간을 지정할 수 있는 `siseJson` 주소를 직접 부른다.

상장폐지 종목을 빼면 살아남은 종목만 보게 되어 결과가 좋게 나온다(생존편향). 이를 막으려고 KIND 에서 2008년 이후 코스피·코스닥 상장폐지 종목 936개를 받아 넣는다.
네이버는 상장폐지 종목 시세를 2008년 무렵부터만 준다. 2005~2007년에 폐지된 종목은 시세가 없어서 기간을 2008년부터로 잡았다.
`KRX_ID` / `KRX_PW` 환경변수가 있으면 대신 pykrx 로 시작 월부터 매달 첫 거래일의 상장 목록을 모은다.

빼는 종목과 구간:

- 우선주(종목코드 끝자리가 0 이 아님), 스팩, 리츠, 선박투자회사("○○9호"). ETF·ETN 은 주식 목록에 원래 없다.
- 상장 후 25거래일이 안 된 구간 (25일선이 없다)
- 거래량 0 인 날(거래정지)
- 20일 평균 거래대금 10억 원 미만. 거래대금은 종가 × 거래량으로 어림한다(네이버 시세에 거래대금이 없다).
- 상장폐지 종목의 마지막 7거래일(정리매매). 가격 제한이 없어 하루 -50% 도 나오는데, 정리매매는 그때 이미 공시된 사실이라 빼도 미래 정보를 쓰는 게 아니다.
- 시세가 끊긴 날부터 25거래일. 네이버가 액면분할·감자를 반영하지 못한 종목이 가끔 있다. 가격 제한(2015-06-15 전 ±15%, 이후 ±30%)을 넘게 움직인 날과 3거래일 넘는 거래정지가 풀린 날을 끊김으로 본다.
- 끊긴 날을 끼고 들고 있던 거래(재개일에 반 토막 이하·두 배 이상, 또는 가격 제한 초과)는 결과에서 뺀다. 2008년 이후 312개 종목, 조합당 60건쯤이다.

## 매매 규칙

- 신호: 종가 기준 이격도(종가 ÷ 25일선 × 100) ≤ 기준값
- 진입: 신호 다음 거래일 시가. 그날 거래정지면 신호를 버린다.
- 청산(먼저 오는 것):
  1. 종가가 25일선 이상 → 다음 거래일 시가
  2. 시가가 손절가 아래 → 시가, 장중 저가가 손절가 이하 → 손절가
  3. 최대 보유일 도달 → 그날 종가. 보유일은 진입일을 1일째로 센다. 거래정지일도 세지만 그날은 팔지 않고 다음 거래일 종가에 판다.
  4. 데이터가 끝남(상장폐지, 긴 거래정지) → 마지막 거래일 종가, `forced`
- 같은 종목을 들고 있는 동안의 신호는 무시한다.
- 비용: 수수료 매수·매도 각 0.015%, 슬리피지 편도 0.1%, 매도세는 매도일 기준 그해 세율(2019-05 전 0.30%, 0.25%, 2021 0.23%, 2023 0.20%, 2024 0.18%, 2025 0.15%, 2026 0.20%). 코스피(거래세+농특세)와 코스닥 합계가 해마다 같다.

모든 값은 `config.yaml` 에서 바꾼다. 신호일 종가 매수, 25일선 회복일 종가 청산도 옵션으로 있다.

## 파라미터 그리드

이격도 기준 6개(95, 90, 85, 80, 75, 70) × 손절 4개(없음, -5%, -8%, -12%) × 최대 보유일 4개(3, 5, 10, 20) × 시장 필터 5개(없음, 상승장만, 동반급락 95·97·99) × 시장 3개(코스피, 코스닥, 합산) = 1,440개 조합.
시장은 같은 거래를 나눠 보는 것이라 시뮬레이션은 종목마다 480번 돈다. 거래 한 건씩 도는 반복문은 numba 로 컴파일하고, 종목은 6개 프로세스에 나눠 돌린다.

## 결과 요약 (2008-01 → 2026-09, 3,243개 종목, 비용 포함)

- 이격도가 낮을수록 거래당 기대값이 높다. 합산·손절 없음·시장 필터 없음·20일 보유 기준으로 ≤95 는 -0.23%, ≤85 는 +1.7%, ≤70 은 +6.4% 다.
- 지수 120일선 필터(상승장만)는 비교한 216쌍 중 한 쌍도 낫지 않았다. 폭락장 매수를 막아 버린다.
- 지수도 같이 빠진 날만 사는 동반급락 필터(신호일 지수 이격도 ≤ 95, 97, 99)는 세 기준 모두 216쌍 전부에서 나았다.
  코스피 평균 기대값은 필터 없음 +2.2%, ≤99 +3.1%, ≤97 +3.7%, ≤95 +4.5% 다.
- 1등 조합은 코스피 / 이격도 ≤70 / 손절 없음 / 20일 / 동반급락 ≤95 로, 거래 804건에 거래당 +19.8%, 승률 80% 다.
  폭락 구간 6개(2008-10, 2011-08, 2020-03, 2022, 2024-08, 2026-06~08)를 빼도 거래당 +14.4% 다.
- 2008~2016 과 2017~2026 의 조합 순위 상관은 0.90 이다.
- 그러나 1억·5종목으로 굴리면 코스피 지수 보유를 넘지 못한다. 코스피 / 이격도 ≤70 / 손절 -8% / 20일 보유 조합을 필터만 바꿔 돌린 결과:

  | 시장 필터 | 연환산 | 최대 낙폭 | 2008~2016 | 2017~2026 | 돈이 들어가 있는 날 |
  |---|---|---|---|---|---|
  | 없음 | -6.1% | -87% | +0.0% | -11.4% | 85% |
  | 상승장만 | -11.9% | -91% | -1.1% | -20.8% | 63% |
  | 동반급락 ≤95 | +6.2% | -62% | +3.2% | +9.0% | 16% |
  | 동반급락 ≤97 | +6.8% | -64% | +0.1% | +13.4% | 25% |
  | 동반급락 ≤99 | +5.8% | -72% | +3.1% | +8.4% | 43% |
  | 코스피 지수 보유 | +7.4% | -50% | +1.0% | +13.7% | 100% |

  2015년부터만 보면 동반급락 ≤97 이 연 +12.5%, 최대 낙폭 -28% 였는데, 2008년 금융위기를 넣으니 낙폭이 -64% 로 커졌다.
  2008~2009년에는 지수가 몇 달 동안 25일선 아래에 머물렀다. 그동안 구조조정에 들어간 건설·조선주가 계속 신호를 냈고,
  같은 종목을 네다섯 번씩 다시 사서 -8% 손절을 거듭했다. 2009년에 코스피는 +50% 였지만 이 조합은 -26% 였다.
- 거래당 기대값이 높아도 신호가 폭락 며칠에 몰려서, 5종목만 사는 포트폴리오로는 대부분 놓친다.

## 돌리는 법

```
pip install -r requirements.txt
python -m src.fetch        # 시세 수집. 처음엔 약 35분(3,243개, 요청 사이 0.3초). 다시 돌리면 새 날짜만 받는다
python -m src.grid         # 1,440개 조합 시뮬레이션과 요약
python -m src.checks       # 검증 체크리스트
python -m src.portfolio    # 상위 5개 조합 포트폴리오
python -m src.report       # 히트맵과 report.md
```

한 종목만 들여다볼 때:

```
python -m src.simulate 005930 85 -0.08 10 crash97   # 종목, 이격도 기준, 손절(none 가능), 최대 보유일, 시장 필터
```

## 파일

```
config.yaml          모든 파라미터
src/fetch.py         종목 목록, 지수, 시세 수집 (data/ 에 parquet 캐시)
src/indicators.py    25일선, 이격도, 거래대금, 지수 120일선 필터
src/simulate.py      거래 한 건씩 시뮬레이션 (numba)
src/grid.py          파라미터 그리드, grid_summary.csv
src/checks.py        검증 체크리스트, 단순 반복문으로 다시 계산해 대조
src/portfolio.py     1억 원, 최대 5종목 포트폴리오
src/report.py        히트맵, report.md
results/             trades.parquet, grid_summary.csv, heatmap_*.png, report.md
```

차트는 한국식으로 이익은 빨강, 손실은 파랑이다.
