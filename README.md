# trading_algorithm_backtest

한국·미국 주식의 매매 규칙을 일봉으로 백테스트한 모음이다. 단기 평균 회귀, 추세 추종, 지수 타이밍, 자산배분, 레버리지 ETF 분할 매수까지 연구 폴더 11개에 나눠 판정했다. 알고리즘 하나에 폴더 하나를 두고, 폴더마다 지시서(`SPEC.md`), 설정(`config.yaml`), 코드, 결과 설명(`README.md`), 판단 기록(`NOTES.md`)이 있다.
주문 코드와 증권사 API 연결은 없다. 결과 파일(`results/`)은 저장소에 올리지 않으므로 폴더마다 직접 돌려야 한다.

2026-09-29 기준. 미리 정한 기준을 모두 넘어 "후보"로 올린 규칙은 하나도 없다. 앞으로 쌓이는 데이터로 판정 중인 것이 둘 있다(아래 「지금 돌고 있는 것」).

## 지금까지 배운 것

1. **비용의 벽.** 자주 사고파는 규칙은 거의 모두 비용에 졌다.
   - 미국 ETF: 편도 0.12% 를 한 해 30번 안팎 물면 연 7%p 가 빠진다. 밤사이 보유(S9)는 비용 없이 연 +6.2 → +10.6% 인데 비용을 넣으면 연 -40% 안팎이다.
   - 한국 개별주: RSI(2) 는 거래 단위로 승률 58% 에 거래당 +0.16% 지만, 한 해 263번 사고팔아 왕복 비용 0.4 → 0.5% 가 이익을 거의 다 먹는다. 하루짜리 변동성 돌파는 연 -38% 다.
   - 반대로 한 해 12번 이하로 바꾸는 규칙(월간 배분, 주 1회 변동성 목표)은 비용이 연 0.2 → 0.6%p 라 문제가 아니었다. 이 규칙들은 비용이 아닌 다른 기준에서 떨어졌다.
2. **한국 개별주는 떨어진 뒤 오르고, 오른 뒤 되밀린다.**
   - bnf: 지수도 같이 폭락한 날 25일선보다 크게 떨어진 종목을 사면 거래당 +19.8% 다. 같은 날 아무 종목을 사도 +16.4% 라서, 수익 대부분은 "폭락한 날 산다"에서 온다.
   - 터틀: 신고가를 넘은 종목을 사면 거래당 -6.3 → -7.5% 로, 무작위 종목(-4.0%)보다 더 잃는다. 무작위 종목·날짜의 46% 가 20거래일 안에 2N 손절선에 닿을 만큼 크게 튀고, 20거래일 수익의 중앙값은 -1.8% 다.
   - 예외는 필터를 겹겹이 건 돌파다. 미너비니 템플릿(이평선 정배열 + RS ≥ 70 + 52주 조건 + 지수 국면)은 무작위 진입 200번을 모두 이겼다. 그러나 낙폭이 -76% 였고, 이익이 몇 해(2019, 2020, 2024, 2025)에 몰렸다.
3. **거래 단위로 강한 규칙이 계좌로는 약할 수 있다.** bnf 동반급락은 이익의 65% 가 신호일 5일에 몰려, 자리 5개로는 대부분을 놓친다. RSI(2) 와 미너비니도 무작위보다 낫지만 계좌 곡선은 낙폭 -75% 안팎이다. 거래 단위 숫자만 보고 판단하지 않는다.
4. **지수 타이밍과 자산배분은 "덜 들고 있기"보다는 낫지만 공짜가 아니다.**
   - 미국 SPY 에서 200일선, 10개월선, 변동성 목표 모두 같은 낙폭의 고정 비중보다 연 2.3 → 3.6%p 더 벌었다. 그러나 보유보다 1.4 → 3.5%p 덜 벌었다.
   - 월간 배분 규칙도 같은 낙폭의 고정 비중보다 연 0.8 → 3.3%p 더 벌었지만, 샤프로는 5종목 동일 비중과 거의 같았다. 단순 SPY 60 / TLT 40 이 세 규칙보다 샤프가 높았다.
   - 한국은 2026-06 → 08 급락을 추세 규칙이 피하지 못했다.
5. **레버리지 ETF 는 규칙보다 들고 있는 편이 나았다.** 무한매수법은 TQQQ 에서 연 +30% 였지만 낙폭 -80% 가 보유와 비슷하고, 같은 낙폭의 보유는 연 +42% 였다. 밸류 리밸런싱은 TQQQ 에서 낙폭을 -27% 로 줄여 같은 낙폭의 보유보다 연 3.1%p 높았지만, 앞 절반(2010 → 2018)에서는 졌다.
6. **가설을 만든 자료에서만 좋게 나온다.** IBS 의 반등 효과는 가설을 만든 4개 ETF 에서는 뚜렷했지만, 새 ETF 6개에서는 방향만 같고(5/6) 크기가 작았다. 변동성 목표도 2008 → 2026 에서 낙폭 비율 58% 였지만 1928 → 2006 에서는 71% 였다.
7. **검증 방법에 대해.**
   - 거래 단위 Deflated Sharpe 는 거래가 같은 날 몰리면 너무 후하다(bnf: 거래 804건 기준 1.00, 신호일 119개 기준 0.53). 신호일(진입일) 단위로 잰다.
   - 상승장 필터(지수가 이평선 위일 때만 산다)는 평균 회귀에 해롭다. bnf 에서 216쌍 중 한 쌍도 낫지 않았다. 반대로 추세 추종(미너비니·오닐)에서는 손실을 줄였다.
   - 비교 기준은 단순 보유만으로는 부족하다. 같은 낙폭이 되게 비중을 맞춘 보유, 같은 관리 규칙의 무작위 진입을 같이 본다.
   - 2023 → 2026 은 앞선 폴더들이 이미 돌린 구간이라 깨끗한 표본 밖이 아니다. 새 규칙은 처음부터 봉인할 구간을 정한다.
   - 합성 레버리지 자료는 차입 비용을 빼먹기 쉽다. 원문의 합성 3배 QQQ 는 실제 TQQQ 보다 연 5.9%p 높게 나왔다.

## 공통 조건

- 시세는 저장소 밖에 두고 모든 폴더가 같이 쓴다. 한국 `../krx_data`(네이버 차트, 상장폐지 936개 포함), 미국 `../us_data`(야후, 배당 반영 가격), 추가로 받은 과거·보조 자료 `../hist_data`(S&P 500 지수 1928 → 2006, SCZ, AGG, BIL, QQQ 1999 →), 기록 장치 전용 `../live_data`.
- 비용: 한국 수수료 편도 0.015% + 슬리피지 0.1% + 그해 매도세(2026 0.20%), 미국 수수료 편도 0.07% + 슬리피지 0.05%. 쉬는 돈은 현금 0%(따로 적은 민감도 제외).
- 규칙과 판정 기준은 돌리기 전에 지시서에 고정하고, 결과를 본 뒤 바꾸지 않는다. 바꾸고 싶어지면 새 지시서를 쓰거나 "판정 제외" 민감도로 적는다.
- 순서: 지시서 초안 → 사용자 승인 → 끝까지 돌림 → 검증 → 결과 문서 → 사용자 확인 뒤 푸시.

## 다음에 할 수 있는 것

같은 과거 자료로 새 규칙을 더 시험하는 것은 권하지 않는다. 시행 수만 늘고, 좋게 나와도 믿기 어렵다. 남은 선택지는 셋이다.

1. **기록 장치 두 개를 기다린다.** 가장 값싸고, 판정이 아직 열린 규칙은 이 둘뿐이다.
2. **미너비니 템플릿도 앞으로의 데이터로 기록한다.** 무작위 진입은 크게 이겼고 낙폭에서 졌다. 매일 3,000 종목 신호를 계산해야 해 기록 장치가 크다.
3. **원문 설계서에서 뺀 두 가지.** 분봉 오프닝 레인지 돌파(증권사 API 와 매일 도는 분봉 수집기가 필요)와 오닐 재무 조건(DART API 키가 필요).
