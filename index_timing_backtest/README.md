# index_timing_backtest

목표를 바꿨다. "지수보다 더 번다"가 아니라 **"지수를 들되 수익은 거의 그대로 두고 최대 낙폭을 크게 줄인다"** 를 판정한다. 널리 알려진 지수 타이밍 규칙 3개를 문헌 기본값으로 고정해 미국(SPY)과 한국(코스피)에 한 번씩 돌렸다. 지시서는 [SPEC.md](SPEC.md) 다.
주문 코드, 증권사 API 연결은 없다.

## 규칙

| # | 규칙 | 언제 바꾸나 |
|---|---|---|
| T1 | 종가 > 200일선이면 지수 100%, 아니면 현금 | 매일 |
| T2 | 월말 종가 > 월말 종가 10개 평균이면 다음 달 100%, 아니면 현금(Faber) | 월말 |
| T3 | 비중 = min(1, 15% / 지난 20거래일 연환산 변동성) | 주말, 10%p 넘게 달라질 때만 |

- 신호일 종가로 정하고 다음 거래일 시가에 사고판다. 쉬는 돈은 현금 0%.
- 미국: SPY 배당 반영 가격, 편도 비용 0.12%. 기간 2008-01-02 → 2026-09-25.
- 한국: 코스피 가격 지수에 연 1.7% 배당 근사(0%, 2.7% 민감도), 편도 비용 0.02%(지수 ETF 가정). 기간 2008-01-02 → 2026-09-23.
- 이웃 값: T1 150·250일, T2 8·12개월, T3 12·18%.

## 결과

**판정: 6개(규칙 3 × 시장 2) 모두 탈락이다.** 미리 정한 기준 6개를 모두 만족한 규칙이 없다.

| 시장 | 규칙 | 연 수익률 (보유 대비) | 최대 낙폭 (보유 대비) | 낙폭 맞춘 고정 비중 대비 | 한 해 거래 | 못 넘은 기준 |
|---|---|---|---|---|---|---|
| 미국 | T1 200일선 | +8.3% (-3.0%p) | -25.1% (48%) | +3.1%p | 5.1 | 2 수익, 4 후반 |
| 미국 | T2 10개월선 | +7.7% (-3.5%p) | -26.2% (50%) | +2.3%p | 1.7 | 2 수익, 4 후반 |
| 미국 | T3 변동성 목표 | +9.9% (-1.4%p) | -30.3% (58%) | +3.6%p | 6.8 | 4 후반(-3.4%p, 한도 -3.0%p) |
| 한국 | T1 200일선 | +6.7% (-2.3%p) | -38.6% (77%) | -0.2%p | 8.3 | 1, 2, 3, 4, 5 |
| 한국 | T2 10개월선 | +7.6% (-1.5%p) | -38.5% (77%) | +0.7%p | 2.1 | 1 낙폭, 4, 5 |
| 한국 | T3 변동성 목표 | +6.2% (-2.9%p) | -30.7% (62%) | +0.7%p | 8.8 | 2 수익, 4, 5 |

기준: (1) 낙폭 ≤ 보유의 70%, (2) 수익이 보유보다 1.5%p 넘게 낮지 않음, (3) 낙폭을 맞춘 고정 비중(지수 w + 현금)보다 수익 높음, (4) 전반(2008 → 2016)·후반(2017 → 끝) 모두 낙폭이 얕고 수익 차이 -3%p 이내, (5) 이웃 값 2개도 기준 1·3 만족, (6) 한 해 거래 12번 이하.

- **미국 T3(변동성 목표)가 가장 가까웠다.** 수익은 1.4%p 덜 벌고 최대 낙폭은 -52% 에서 -30% 로 줄었다. 이웃 값 12%, 18% 도 같은 모양이다. 후반(2017 → 2026) 수익이 보유보다 3.4%p 낮아 한도(3.0%p)를 넘은 것 하나로 떨어졌다.
- **미국은 세 규칙 모두 "지수를 덜 들고 있는 것"보다 낫다.** 같은 낙폭이 되게 지수 비중을 낮춘 고정 비중보다 연 2.3 → 3.6%p 더 벌었다. 다만 낙폭을 줄인 만큼 수익을 더 내주어 기준 2 나 4 에 걸렸다.
- **한국은 2026-06 → 08 급락을 T1·T2 가 피하지 못했다.** 2025 → 2026 급등 뒤 3개월 만에 -38.5% 가 나는 동안 200일선·10개월선 아래로 내려가지 않았다. T3 는 변동성이 먼저 커져 그 구간 평균 비중이 23% 였고 구간 낙폭이 -8.7% 였다.
- 한국 배당 가정(0%, 2.7%)을 바꾸면 기준 2·3 일부가 바뀌지만 어느 규칙의 판정도 바뀌지 않는다.

자세한 표는 `results/report.md`, 검증은 `results/checks.md` 에 생긴다(저장소에 올리지 않는다).

## 돌리는 법

```
pip install -r requirements.txt
python -m src.run        # 규칙 18개 + 보유 → results/daily.parquet, weights.parquet, trades.csv
python -m src.metrics    # 지표와 비교 기준 → metrics.csv
python -m src.neighbors  # 이웃 값 → neighbors.csv
python -m src.stress     # 큰 하락 구간 → stress.csv
python -m src.report     # → results/report.md, verdicts.csv
python -m src.checks     # → results/checks.md
```

데이터는 저장소 밖 `../../us_data`(SPY), `../../krx_data`(코스피 지수)를 쓴다.
