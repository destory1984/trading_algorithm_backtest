# crash_etf_backtest

bnf_backtest 에서 가장 강했던 재료 "지수가 25일선보다 5% 넘게 떨어진 날 산다"를, 이 저장소가 한 번도 쓰지 않은 나라별 지수 ETF 19개에 그대로 돌려 판정했다. 지시서는 [SPEC.md](SPEC.md), 배경은 [기획서](../docs/PLAN_2026-10-02.md) 안 C 다.
주문 코드, 증권사 API 연결은 없다.

## 규칙과 조건

- 종목: EWA 호주, EWO 오스트리아, EWK 벨기에, EWC 캐나다, EWQ 프랑스, EWG 독일, EWH 홍콩, EWI 이탈리아, EWJ 일본, EWM 말레이시아, EWW 멕시코, EWN 네덜란드, EWS 싱가포르, EWP 스페인, EWD 스웨덴, EWL 스위스, EWU 영국(1996-03 상장), EWT 대만, EWZ 브라질(2000 상장). 한국(EWY)은 가설을 만든 시장이라 뺐다.
- 신호: 종가 ÷ 25일선 ≤ 0.95. 다음 거래일 시가에 산다. 신호일의 20일 평균 거래대금이 100만 달러 이상일 때만 산다.
- 청산: 종가가 25일선 이상이면 다음 거래일 시가, 아니면 20거래일째 종가. 손절과 재진입 제한은 없다.
- 계좌: 10만 달러를 19칸에 나눠 칸마다 따로 굴린다. 편도 비용 0.12%, 현금 0%, 배당 반영 가격.
- 기간: 1997-01-02 → 2026-09-25. 이웃은 이격도 93, 97.
- 비교: 같은 19개를 사서 들고 있는 바구니, 그 바구니를 같은 낙폭이 되게 줄인 것, 같은 거래 수의 무작위 날짜 진입 200번.

## 결과

**판정: 탈락이다(기준 8개 중 2, 3, 4, 5, 6, 8 을 못 넘었다).** 폭락일 매수는 처음 보는 자료에서 아무 날에 사는 것과 구별되지 않았다.

| 기준 | 결과 | 내용 |
|---|---|---|
| 1 효과가 있다 | O | 거래 1,255건, 거래당 +0.46%, 승률 64%. 평균이 0 보다 큰 종목 14 / 19 (기준 13) |
| 2 무작위 진입 95 백분위 | X | 연 +0.54%. 무작위 200번 중앙값 +0.51%, 95 백분위 +1.06%. 55% 위치 |
| 3 낙폭 맞춘 보유보다 높음 | X | 연 +0.54%, 낙폭 -44.1%. 보유 +6.8% / -63.3%. 낙폭 맞춘 보유(61%) +4.7% 보다 -4.1%p |
| 4 두 기간 | X | 1997 → 2011 -4.8%p, 2012 → 2026-09 -4.2%p |
| 5 이웃 93·97 | X | 93 은 -2.9%p, 97 은 -4.1%p |
| 6 비용 2배 | X | 연 +0.00%, -4.8%p |
| 7 가장 좋은 신호일 5일을 빼도 평균 > 0 | O | +0.09% |
| 8 Deflated Sharpe ≥ 0.95 | X | 0.645 (진입일 샤프 +0.075, 진입일 646개) |

- **승률은 64% 지만 번 것이 없다.** 거래의 69% 는 25일선을 회복해 평균 +4.0% 로 끝났고, 31% 는 20일을 채워 평균 -7.6% 로 끝났다. 합치면 거래당 +0.46% 이고, 30년 동안 연 +0.54% 다. 그 사이 낙폭은 -44% 였다.
- **무작위 날짜에 사도 같았다.** 같은 수의 거래를 아무 날에 놓은 200번의 중앙값이 연 +0.51% 다. 거래당 평균으로 보면 규칙이 무작위의 94% 위치라 방향은 있지만, 계좌로 옮기면 사라지는 크기다.
- **여러 나라가 같이 폭락한 날이 가장 나빴다.** 한국에서는 지수가 같이 빠진 날일수록 좋았는데 여기서는 반대다. 같은 날 5개 이상의 나라에서 신호가 난 56일의 거래 393건은 평균 -0.50%, 나머지 날의 거래는 +0.90% 다. 2008-09-29 신호는 11개 나라 평균 -32.9%, 2020-02-25 신호는 9개 나라 평균 -27.5% 였다. 폭락의 첫 5% 에서 사고 20일 뒤에 더 낮은 값에 판 것이다.
- **가장 좋은 날도 폭락 뒤였다.** 2025-04-04(13개 나라 평균 +11.3%), 2008-10-28(+13.0%), 2016-06-24 브렉시트(+8.1%). 좋은 날과 나쁜 날이 같은 종류의 날이라 미리 가를 수 없다.
- **깊게 떨어질수록 낫다는 방향은 한국과 같다.** 이격도 93 은 거래당 +1.01%, 95 는 +0.46%, 97 은 +0.34% 다. 그러나 93 도 낙폭 맞춘 보유보다 연 2.9%p 낮다.
- **손실은 2008 과 2020 두 해에 몰렸다.** 2008 년 -34.1%(거래 166건, 거래당 -3.9%), 2020 년 -14.0%. 나머지 28해 중 21해는 플러스지만 대부분 +0 → 5% 다.
- **종목별**: 19개 모두 자기 낙폭에 맞춘 보유보다 낮았다(-0.8 → -10.6%p). 손익분기 비용은 합쳐서 편도 35bp 다.

| 비용 0 | +1.09% | -43.3% | -3.5%p |

어느 가정에서도 판정은 같다. Deflated Sharpe 를 한국 누적 시행에 붙여 N = 1,443, bnf 그리드의 분산으로 재면 0.000 이다.

### 한국 결과와 다른 까닭 (해석, 판정 아님)

bnf 의 +16.4% 는 폭락일의 **개별 종목** 평균이었다. 개별 종목은 지수보다 훨씬 크게 떨어졌다가 되돌아온다. 지수 ETF 는 수십 → 수백 종목의 평균이라 그 되돌림이 서로 지워진다. 또 bnf 의 신호일은 119일뿐이었고 이익의 65% 가 그중 5일에서 나왔다. 여기서는 신호일이 646일이고, 가장 나쁜 날들이 가장 좋은 날들과 크기가 같다.

## 데이터에서 알게 된 것

- 1997 → 2003 에는 19개 중 11 → 18개가 거래대금 하한(100만 달러) 아래였다. 그래서 앞 기간 거래 642건의 대부분은 2004 년 이후다. 하한을 없애도 결과는 같았다.
- 거래량 0 인 날이 오스트리아 171일, 벨기에 152일 등 1997 년 이후에도 있다. 그날은 사지도 팔지도 않았다.
- 하루 ±15% 넘게 움직인 37일 가운데 36일은 알려진 사건의 달(1997-10, 1998-02, 1998-09, 2008-09 → 10, 2016-06, 2017-05, 2020-03)이다. 나머지 하나(EWM 1999-08-12 +16.0%)는 사건을 확인하지 못했다. 37일 모두 원래 종가와 배당 반영 종가의 움직임이 같아 분할·병합 오류는 아니다.
- 19개 모두 2026-09-25 까지 거래됐다. 상장폐지된 것은 없다.

## 검증

지시서 5절의 8개 모두 통과했다.

1. 봉인: 가격, 곡선, 거래 모두 2026-09-25 까지다.
2. 미래 데이터 금지: 종목마다 마지막 20거래일 가격을 흔들어도, 그 전에 끝난 거래 4,161건이 하나도 바뀌지 않는다.
3. 손 검산: 5종목 × 2건(25일선 회복 청산, 20일째 청산)을 원래 가격 파일로 다시 계산해 이격도, 진입가, 청산일, 수익이 모두 같다.
4. 단순 반복문으로 3종목 × 3판본을 다시 계산해 거래 수, 날짜, 청산 종류, 수익이 모두 같다.
5. 돈 계산: 칸 자산 = 거래 수익률의 곱(차이 5e-15), 바구니 = 칸 평균. 겹친 거래 0건, 거래량 0 인 날 체결 0건.
6. 무작위 진입 251,000건이 모두 살 수 있는 날이고 겹치지 않으며 거래 수가 규칙과 같다.
7. Deflated Sharpe 손계산 0.6446, 코드 0.6446.
8. 큰 움직임 37일 중 분할·병합 오류로 보이는 날 0개.

자세한 표는 `results/report.md`, 검증은 `results/checks.md`, 데이터 점검은 `results/data_check.md` 에 생긴다(저장소에 올리지 않는다).

## 돌리는 법

```
cd crash_etf_backtest
pip install -r requirements.txt
python -m src.fetch        # 한 번만. 파일이 있으면 멈춘다
python -m src.data_check
python -m src.run
python -m src.metrics
python -m src.monkey
python -m src.overfit
python -m src.crashes
python -m src.report
python -m src.checks
```

가격은 저장소 밖 `../../hist_data/country/` 에 받는다(환경변수 `HIST_DATA_DIR` 로 바꿀 수 있다). Deflated Sharpe 민감도는 `../bnf_backtest/results/trades.parquet` 가 있을 때만 나온다. 모든 값은 `config.yaml` 에 있다.
