# ibs_lev_backtest

[CazSyd/IBS-Strategy](https://github.com/CazSyd/IBS-Strategy)가 내세운 다섯 가지 주장을 우리 데이터와 코드로 따로 검증한다. 레버리지 ETF(TQQQ, SPXL, SOXL) 백테스트와 한국 거주자 양도소득세 계산에는 지시서가 고정한 기본 규칙(추세 필터 없음, 손절 없음)만 쓴다 — C1(엣지 존재)은 진행 게이트, C1·C3(200일선 아래 엣지)은 판단 기준(「미리 정한 판단 기준」)에 들어가지만, C3 을 반영한 200일선 아래 매수 변형이나 C5 를 반영한 레버리지 ETF 바구니는 만들지 않았다.
엔진은 [krx_backtest_core](https://github.com/destory1984/krx_backtest_core) v0.2.1 을 그대로 쓰고, 이 저장소에는 규칙과 검증 코드만 둔다. 주문 코드, 증권사 API 연결은 없다.

## 규칙

- IBS = (종가 − 저가) / (고가 − 저가). 고가 = 저가인 날은 신호를 내지 않는다(NaN; `ibs_backtest` 는 이런 날을 0.5 로 두어 여기와 다르다).
- 진입: 보유하지 않은 상태에서 전날 IBS < 0.13 이면 오늘 시가에 산다. 청산: 보유 중 전날 IBS > 0.5 이면 오늘 시가에 판다.
- 문턱값 0.13 / 0.5 는 고정이고 그리드를 돌리지 않는다. 원본이 문턱값 표면을 표본 앞뒤 절반으로 나눠 봤더니 상관 −0.07 로 재현되지 않는다고 밝혔기 때문이다.
- 손절 없음, 추세 필터 없음, 한 번에 한 포지션, 레버리지 추가 없음. 쉬는 현금은 13주 국채 금리(^IRX, 전날 값)만큼 이자를 받는다(또는 0, 두 경우 다 낸다).

체결은 두 가지를 나란히 본다.

| 이름 | 진입 | 청산 |
|---|---|---|
| `open` | 전날 신호로 오늘 시가에 (원본 방식) | 전날 신호로 오늘 시가에 |
| `close` | 신호일 종가에 (`ibs_backtest` 와 같은 뜻) | 청산 신호일 종가에 |

## 결과

### 단계 0: 원본 패키지 재현 (--end 2026-07-31, 비용 0, 현금 ^IRX)

| 구간·사이징 | 연 수익률 원본/재현 | 샤프 원본/재현 | 최대 낙폭 원본/재현 | 거래 원본/재현 |

| TQQQ 합성 포함 1999.3→2026.7 전액 | +29.6% / +29.8% | 0.79 / 0.80 | -70.7% / -70.7% | 753 / 753 |
| TQQQ 합성 포함 1999.3→2026.7 변동성 0.4 | +16.7% / +16.9% | 0.87 / 0.88 | -34.5% / -34.5% | 753 / 753 |
| SPXL 합성 포함 1993.2→2026.7 전액 | +22.6% / +23.0% | 0.83 / 0.84 | -51.5% / -51.5% | / 929 |

우리 엔진 + 계좌 대조(TQQQ 실제 구간, 비용 0, ^IRX, 전액, open, 1만 달러): 원본 거래 392건·연 +20.6%·샤프 0.78·낙폭 -39.2%, 우리(irx_lag 0/1 둘 다) 거래 392건·연 +20.5%·샤프 0.78·낙폭 -39.2%다. 진입일이 같은 날이 392/392, IBS 값 자체가 갈리는 날은 4,141일 중 1일뿐이다.

### 단계 1: 다섯 가지 주장

| # | 주장 | 판정 | 원본 수치 |
|---|---|---|---|
| C1 | IBS 가 낮을수록 다음 날 수익이 높다 | 재현됨 | SPY +0.088% (t 3.05), QQQ +0.144% (t 3.02) |
| C2 | 주식에만 있고 채권·금에는 없다 | 재현됨 | 주식 대부분 t > 2, TLT t 0.89, GLD t -0.78 |
| C3 | 엣지는 지수가 200일선 아래일 때만 있다 | 재현됨 | SPY 위 +0.016% (t 0.61), 아래 +0.226% (t 3.38) |
| C4 | 반등은 밤사이에 시작한다 | 재현됨 | 하위 20% 날 종가 → 다음 날 시가 t 2.7 → 3.6 |
| C5 | 여러 자산에 나눠 담으면 낙폭이 준다 | 재현됨 | 수익 상관 0.21, 샤프 0.72 → 1.14, 낙폭 -22% → -16% |

우리 재측정(no_gap, 2008-01-01 → 2026-07-31): C1 SPY +0.103% (t 2.57, n 927), QQQ +0.167% (t 3.67, n 924). C3 SPY 200일선 위 -0.009%(t -0.30) 아래 +0.329%(t 3.21), QQQ 위 +0.023%(t 0.60) 아래 +0.507%(t 4.18). 자세한 표는 `results/claims.md` 에 있다.

### 단계 2: TQQQ / SPXL / SOXL 조합표 (open, 비용 포함, ^IRX)

세전/세후는 1억 원 기준. 1배 = 기초지수 1배 ETF 보유(TQQQ→QQQ, SPXL→SPY, SOXL→SOXX).

| 종목 | 사이징 | 연 수익률 세전/세후 | 샤프 | 최대 낙폭 | 1배 보유 연수익/샤프 |
|---|---|---|---|---|---|
| TQQQ | 전액 | +15.7% / +12.5% | 0.65 | -43.4% | +19.2% / 0.96 |
| TQQQ | 변동성 0.4 | +12.0% / +9.7% | 0.70 | -36.8% | +19.2% / 0.96 |
| SPXL | 전액 | +6.4% / +4.6% | 0.36 | -58.1% | +14.3% / 0.82 |
| SPXL | 변동성 0.4 | +5.0% / +3.7% | 0.35 | -35.8% | +14.3% / 0.82 |
| SOXL | 전액 | +23.1% / +18.4% | 0.70 | -59.6% | +24.7% / 0.87 |
| SOXL | 변동성 0.4 | +10.6% / +8.1% | 0.60 | -46.0% | +24.7% / 0.87 |

전체 조합(96행, 3종목 × open/close × 전액·변동성 0.2/0.3/0.4 × 현금 zero/irx × 비용 있음/없음)은 `results/report.md`, `results/lev.csv` 에 있다.

- 비용이 줄이는 연 수익률의 중앙값: +3.7%p(costs = with vs zero).
- 세금이 줄이는 연 수익률(open·비용 포함·^IRX 행, 세전 대비 세후 CAGR 차이)의 중앙값: 3천만 원 1.29%p, 1억 원 1.83%p, 3억 원 1.99%p.
- **신호 알림 후보로 올리지 않는다: 기준 셋(샤프 > 1배, 낙폭 > -40%, 세후 ≥ 1배 세후)을 모두 넘는 조합 0/18 (샤프 0, 낙폭 16, 세후 0).**

## 돌리는 법

```
pip install -r requirements.txt
pip install -e ../krx_backtest_core
```

`requirements.txt` 의 깃허브 pin 만으로는 `python -m src.checks` 의 `engine_pinned` 검증(krxbt 가 이 모음 저장소의 `krx_backtest_core` 를 가리키는지)을 통과하지 못한다. 반드시 로컬 편집 가능 설치로 다시 깐다.

미국 데이터는 저장소 밖 `../../us_data` 를 다른 백테스트와 같이 쓴다. `watchlist.txt` 에 16개 종목(비레버리지 13개, FXI 포함 + TQQQ, SPXL, SOXL)이 있어야 한다. 다른 백테스트가 `us_data` 를 읽는 동안에는 받지 않는다. 새로 필요한 종목만 받는다.

```
python -m krxbt.fetch_us --dir ../../us_data --tickers XLF XLK XLE SOXX EEM EFA FXI TLT GLD TQQQ SPXL
```

`^IRX` (13주 국채 금리)는 `us_data` 에 없어 `src/data.py` 가 yfinance 로 따로 받아 `results/irx.parquet` 에 캐시한다.

단계 0(원본 패키지 재현)은 `uv` 와, 모음 저장소 밖에 원본 저장소를 따로 받은 것이 있어야 한다(`../../_ref/IBS-Strategy`).

```
python -m src.stage0 --run    # 단계 0: uv 로 원본 CLI 다섯 번 실행 + TQQQ 거래 내보내기
python -m src.claims          # 단계 1: 다섯 주장
python -m src.crosscheck      # 우리 엔진 vs 원본 패키지 대조
python -m src.backtest        # 단계 2: 레버리지 ETF 조합, 96행 2초
python -m src.aftertax        # 단계 3: 세후, 3개 자본 x 96행 = 288행
python -m src.checks          # 검증 → results/checks.md
python -m src.report          # results/report.md
```

모든 파라미터는 `config.yaml` 에 있다. 돌리기 전에 고정했고 결과를 보고 바꾸지 않았다.

## 한계

- 실제 상장 구간만 썼다(TQQQ 2010-02-11부터, SPXL 2008-11-05부터, SOXL 2010-03-11부터). 닷컴 폭락(2000 → 2002)은 표본에 없고, 2008 금융위기는 SPXL 상장 뒤 몇 달만 들어 있다. 합성 과거 구간 수치는 단계 0 의 원본 패키지 결과로만 인용한다.
- `us_data` 가 2007년부터라 단계 1의 주장 검증은 2008년부터고, 원본의 1993/1999년 시작보다 짧다.
- 단계 1 → 3 은 2026-07-31 을 포함해 끝난다. 단계 0 의 원본 패키지는 `--end 2026-07-31` 이 그날을 빼서(원본의 `--end` 가 배타적 경계라) 하루 앞(2026-07-30)에서 끝난다.
- 환율은 1,350원/달러로 고정했다. 환율 변동은 넣지 않았다.
- 쉬는 현금의 이자에는 세금을 매기지 않았다.
- 세금은 해당 연도(Y)분을 다음 해(Y+1) 5월 첫 거래일에 계좌에서 뗀다. 마지막 해(2026년)는 표본 안에 다음 해 5월이 없어 마지막 날에 뗀다.
- 세금 납부일에 그 전에 산 포지션이 열려 있으면(정리해서 낼 수 없으니) 세금만큼 현금이 음수가 될 수 있다.
- `close` 체결은 신호일 종가에 사고파는 것이라 실제로는 종가 동시호가(MOC) 주문이 필요하다.
- k배 벤치마크(1배 ETF 를 전략의 낙폭에 맞춘 비중)는 비중이 1 을 넘지 않게 잘랐다. 전체 96행 중 39행은 전략 낙폭이 1배 ETF 보다 깊어 이 상한에 걸리고(`*` 표시), 이 행에서는 k배 낙폭이 전략 낙폭과 맞지 않는다. k배에는 매매 비용이 없고 세금은 한 번만(마지막에 팔 때) 낸다.
