# 레버리지 ETF IBS 백테스트 작업 지시서

대상 전략: 20선 2번, CazSyd/IBS-Strategy
작성일 2026.9.28. 1번 지시서(SPY IBS)로 만든 `ibs_backtest` 저장소를 이어서 쓴다. 이 문서를 Claude Code에 그대로 넘긴다.

> 사용자가 2026-09-28 대화창에 올린 원문을 그대로 옮겼다. 판단과 차이는 [NOTES.md](NOTES.md) 에 있다.
> 지시서는 `ibs_backtest` 를 이어 쓰라고 했지만, 사용자 지시로 모음 저장소에 폴더를 따로 만들었다(`ibs_lev_backtest/`).
> 그래서 지시서의 `src/lev/…` 는 `src/…`, `results/lev/…` 는 `results/…` 다.
> 지시서의 `../us_data` 는 `../../us_data`, `../_ref` 는 `../../_ref`(모음 저장소 밖)다.

## 목적

1번이 "규칙이 돈을 버는가"를 봤다면, 2번은 "왜 버는가"를 확인한다. 원본 저장소가 내세운 다섯 가지 주장을 우리 엔진과 코드로 따로 검증하고, 살아남은 주장만 레버리지 ETF(TQQQ, SPXL, SOXL) 백테스트에 반영한다. 주문 코드는 만들지 않는다.

## 전략 규칙

- IBS = (종가 - 저가) / (고가 - 저가). 고가 = 저가인 날은 신호를 내지 않는다(원본 방식. 1번과 다르니 주의).
- 진입: 보유하지 않은 상태에서 전날 IBS < 0.13 이면 오늘 시가에 산다.
- 청산: 보유 중 전날 IBS > 0.5 이면 오늘 시가에 판다.
- 손절 없음, 추세 필터 없음, 한 번에 한 포지션, 레버리지 추가 없음
- 쉬는 현금은 13주 국채 금리(^IRX)만큼 이자를 받는다.

원본은 0.13 / 0.5를 최적화로 고르지 않았다고 밝혔다. 문턱값 표면이 표본 앞뒤 절반에서 상관 -0.07로 재현되지 않았기 때문이다. 그래서 이 작업도 **문턱값 그리드를 돌리지 않는다.** 고정값 하나로 간다.

## 라이선스 주의

원본 저장소에는 라이선스 파일이 없다. 원본 코드를 `ibs_backtest`에 복사하지 않는다. 저장소 밖(`../_ref/IBS-Strategy`)에 따로 받아 실행만 하고, 우리 코드는 새로 쓴다.

## 단계 0: 원본 패키지로 재현

1. `../_ref/IBS-Strategy`에 받아 `uv sync`, `uv run pytest`를 돌린다. 테스트가 깨지면 멈추고 보고한다.
2. 아래를 돌려 위 표와 비교한다. 끝 날짜는 2026-07-31로 맞춘다.
   - `uv run ibs backtest TQQQ --end 2026-07-31 --no-plot`
   - `uv run ibs backtest TQQQ --extend QQQ --end 2026-07-31 --no-plot`
   - 위 둘에 `--position-sizing vol_target --target-vol 0.4`
   - `uv run ibs backtest SPXL --extend SPY --end 2026-07-31 --no-plot`
3. 야후 수정주가가 바뀌어 작은 차이는 날 수 있다. 연 수익률이 2%p 넘게 다르면 원인을 찾아 NOTES.md에 적는다.

## 단계 1: 다섯 가지 주장 독립 검증

원본 코드를 쓰지 않고 `src/lev/claims.py`에 새로 짠다. 데이터는 `../us_data`에 아래 종목을 watchlist로 추가해 `krxbt.fetch_us`로 받는다.

SPY, QQQ, IWM, DIA, XLF, XLK, XLE, SOXX, EEM, EFA, TLT, GLD, TQQQ, SPXL, SOXL, ^IRX(받히지 않으면 yfinance로 따로 받는다)

측정 단위는 모두 같다. **IBS 하위 20% 날의 다음 날 시가 → 종가 수익률**과 그 t값이다.

| # | 주장 | 확인 방법 | 원본 수치 |
|---|---|---|---|
| C1 | IBS가 낮을수록 다음 날 수익이 높다 | 10분위별 평균, 하위 20%의 t값, 앞뒤 절반 일치도 | SPY +0.088%(t 3.05), QQQ +0.144%(t 3.02) |
| C2 | 주식에만 있고 채권·금에는 없다 | 13개 ETF 전체 표 | 주식 10개 중 대부분 t > 2, TLT t 0.89, GLD t -0.78 |
| C3 | 엣지는 지수가 200일선 아래일 때만 있다 | 신호 전날 지수(NDX, SPX) 200일선 위·아래로 나눔 | SPY 위 +0.016%(t 0.61), 아래 +0.226%(t 3.38) |
| C4 | 반등은 밤사이에 시작한다 | 하위 20% 날의 종가 → 다음 날 시가 수익률 | t 2.7에서 3.6 |
| C5 | 여러 자산에 나눠 담으면 낙폭이 준다 | QQQ, IWM, TLT, GLD, EEM, XLE 6개에 같은 규칙, 동일 비중 | 전략 수익 상관 0.21, 샤프 0.72 → 1.14, 낙폭 -22% → -16% |

주의할 것:
- 야후 지수 데이터는 2010년 무렵까지 시가 = 전날 종가인 날이 많아 C1을 부풀린다고 원본이 경고했다. 시가 = 전날 종가인 날의 비율을 종목별로 세고, 그런 날을 뺀 결과도 같이 낸다.
- 표본은 2008년부터로 한다(us_data 시작점). 원본보다 기간이 짧으니 t값이 작게 나올 수 있다.

결과는 `results/lev/claims.md`에 주장별로 "재현됨 / 약함 / 재현 안 됨"을 붙여 정리한다.

## 단계 2: 레버리지 ETF 백테스트

단계 1에서 C1이 재현된 경우에만 진행한다. 재현되지 않으면 멈추고 보고한다.

엔진은 1번과 같은 `krxbt.engine.run`을 쓴다. 규칙이 "전날 IBS로 오늘 시가"이므로 `rules.entry_on_signal_close: false`, `rules.target_exit_on_close: false`로 두면 원본과 같다. 고가 = 저가인 날은 `cand`, `target` 둘 다 false로 둔다.

| 항목 | 값 |
|---|---|
| 종목 | TQQQ(2010.2부터), SPXL(2008.11부터), SOXL(2010.3부터) 실제 상장 구간만 |
| 체결 | open, close (close는 1번과 같은 뜻) |
| 사이징 | 전액, 변동성 목표 0.2, 0.3, 0.4 |
| 현금 이자 | 0, ^IRX |
| 비교 기준 | 종목 보유, 기초지수 1배 ETF 보유, 기초지수 1배 ETF를 전략의 최대 낙폭에 맞춰 줄인 보유 |

- 합성 과거 데이터는 만들지 않는다. 실제 상장 구간만 쓰고, 닷컴·금융위기 구간이 빠진다는 점을 보고서 첫머리에 적는다. 합성 구간 결과는 단계 0의 원본 패키지 수치로만 인용한다.
- 변동성 목표 사이징: 진입할 때 비중 = min(1, 목표 / 최근 20거래일 실현 변동성의 연율화). 보유 중에는 비중을 바꾸지 않는다. 엔진이 비중을 지원하지 않으면, 거래 목록을 받은 뒤 `src/lev/sizing.py`에서 일별 자산곡선을 따로 만든다.
- 비용: 수수료 편도 0.07%(`us.costs`)에 슬리피지 TQQQ 2bp, SPXL 4bp, SOXL 4bp. 비용 0 결과도 같이 낸다.
- 조합은 3 × 2 × 4 × 2 = 48개다. 문턱값은 바꾸지 않는다.

## 단계 3: 한국 거주자 세금 반영

원본은 세금을 가장 큰 마찰로 꼽았다(연 28회 정도 단기 차익 실현). 한국 거주자 기준으로 따로 계산한다.

- 해외주식 양도소득세 22%, 연 250만 원 기본공제, 같은 해 손익은 통산한다.
- 달러 손익을 원화로 바꿀 때는 `config.yaml`의 고정 환율(기본 1,350원)을 쓴다. 환율 변동은 무시한다고 보고서에 적는다.
- 매년 말 세금을 계좌에서 뺀 세후 자산곡선을 만든다. 보유 전략은 마지막 해에 한 번에 판다고 가정하고 같은 방식으로 세금을 뗀다.
- 초기 자본은 1억 원 상당(달러 환산)으로 한다. 공제 250만 원의 효과가 자본 크기에 따라 달라지므로 3천만 원, 3억 원도 같이 돌린다.

2. 단계 1 주장별 판정표
3. 단계 2 조합표. 종목별로 연 수익률, 샤프, 최대 낙폭, 노출, 세전·세후를 나란히
4. 단계 3 세후 비교(자본 크기 3가지)
5. C3 결과가 bnf_backtest의 "상승장 필터는 216쌍 모두에서 졌다"와 같은 방향인지 한 문단
6. 한 줄 결론

## 검증 체크리스트

- 미래 데이터 금지: 마지막 20일 가격을 바꿔도 그 전 신호와 거래가 바뀌지 않는다.
- 변동성 계산에 신호일 당일 수익률까지만 들어가고, 진입일 수익률은 들어가지 않는다.
- 현금 이자는 전날 ^IRX 값을 쓴다.
- 세금: 손실인 해는 세금 0, 공제는 해마다 새로 적용된다.
- 원본 패키지와 우리 엔진을 같은 조건(TQQQ 실제 구간, 비용 0, 현금 이자 ^IRX, 전액)으로 돌려 거래 수와 연 수익률이 맞는지 대조한다. 거래 수가 5% 넘게 다르면 멈추고 원인을 찾는다.

## 미리 정한 판단 기준

아래를 모두 만족하면 신호 알림 후보로 올린다.

- 단계 1에서 C1과 C3이 재현된다.
- 단계 2에서 `open` 체결, 비용 포함, 변동성 목표 사이징 조합의 샤프가 기초지수 1배 보유보다 높다.
- 같은 조합의 최대 낙폭이 -40%보다 얕다.
- 단계 3 세후 결과가 1억 원 기준으로 1배 보유 세후 결과보다 낮지 않다.
