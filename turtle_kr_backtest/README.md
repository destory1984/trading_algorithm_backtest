# turtle_kr_backtest

커티스 페이스의 『Way of the Turtle』(2007)에 나온 터틀 규칙을 코스피·코스닥 개별 종목에 매수만으로 돌려, 같은 낙폭의 코스피 보유와 무작위 종목 매수를 이기는지 판정했다. 지시서는 [SPEC.md](SPEC.md) 다.
주문 코드, 증권사 API 연결은 없다.

## 규칙 (책의 값, 매수만)

| | S1 | S2 |
|---|---|---|
| 진입 | 고가가 직전 20거래일 최고가를 넘으면. 직전 20일 돌파(가상 거래)가 이익이었으면 건너뛰고, 그래도 55일 돌파면 산다 | 고가가 직전 55거래일 최고가를 넘으면 |
| 청산 | 저가가 직전 10거래일 최저가 아래 | 저가가 직전 20거래일 최저가 아래 |

- 한 단위 = 자산 × 1% / N 주(N = 실제 변동폭 20일 평균). N/2 오를 때마다 한 단위 더, 종목당 4단위, 전체 12단위. 손절은 마지막 산 값 - 2N.
- 체결: 돌파 가격이 정해진 주문으로 보고 max(시가, 돌파 가격)에 산다. 손절·청산은 min(시가, 그 가격)에 판다.
- 불리한 쪽으로 정한 규칙: 산 날 저가가 손절선 아래면 그날 손절, 같은 날 추가와 손절이 겹치면 손절, 상·하한가에 묶인 날은 사지 않음, 같은 날 신호가 많으면 20일 거래대금이 큰 종목부터.
- 종목 거르기와 비용은 bnf 와 같다(3,243종목, 상장폐지 포함, 수수료 0.015%, 슬리피지 0.1%, 그해 매도세). 처음 자산 1억 원, 기간 2008-04-01 → 2026-09-23.
- 이웃: S1 15·25일, S2 45·65일 돌파.

## 결과

**판정: S1·S2 모두 탈락이다. 기준 6개를 하나도 넘지 못했다.**

| | S1 (20일) | S2 (55일) | 무작위 진입 200번 중앙값 | 코스피 총수익 근사 |
|---|---|---|---|---|
| 연 수익률 | -45.5% | -43.7% | -14.2% / -14.8% | +9.8% |
| 최대 낙폭 | -100% | -100% | -96% / -97% | |
| 거래 | 796 | 1,025 | | |
| 승률 | 12% | 11% | 17% | |
| 거래당 평균 | -7.5% | -6.3% | -4.0% (S1 방식 1번) | |
| 손익비 | 0.17 | 0.35 | | |
| 산 날 바로 손절된 거래 | 28% | 35% | 31% | |

- **계좌가 2년 안에 사실상 바닥났다.** S1 은 2008-11 에 자산이 1억 원의 10% 아래로, 2010-05 에 1% 아래로 내려갔다. S2 는 2009-03 에 10%, 2011-11 에 1% 아래였다. 그 뒤로는 한 단위가 몇 주밖에 안 되어 거래가 드물다. 그래서 이후 구간의 수익률보다 거래 단위 숫자가 더 쓸모 있다. 후반(2017 →)에 산 거래만 봐도 거래당 평균이 S1 -5.3%, S2 -4.4% 로 손실이다.
- **돌파한 종목을 사는 것이 무작위 종목을 사는 것보다 나빴다.** 크기·추가·손절·청산이 같은 무작위 진입 200번은 연 -24.2 → +1.2%(S1 방식), -29.1 → +8.9%(S2 방식)였고, 규칙은 그 가장 나쁜 것보다도 나쁘다. 거래당 평균은 무작위 -4.0%, 돌파 -6.3 → -7.5% 다. 시가가 돌파 가격 위에서 열린 날(갭 상승) 산 거래(S1 -8.2%)와 장중에 돌파한 날 산 거래(-7.2%)가 비슷하다. 한국 종목은 신고가를 넘은 뒤 되밀리는 경향이 있다. bnf 에서 본 평균 회귀와 같은 방향이다.
- **2N 손절이 너무 자주 걸린다.** 무작위 종목·날짜 20만 개를 보면, 20거래일 뒤 수익의 중앙값이 -1.8% 이고 46% 가 20거래일 안에 2N 손절선에 닿는다. 한국 종목(상장폐지 포함)은 대부분 조금씩 내리고 가끔 크게 튀는 모양이다. 책이 말한 "30 → 40% 승률, 큰 추세 몇 번으로 번다"가 나오지 않았다.
- **이웃, 비용, 신호 순서를 바꿔도 같다.** 이웃 4개 모두 연 -44 → -45%, 슬리피지 0.1 → 0.5% 모두 연 -44 → -46% 다. 같은 날 신호를 거래대금 순 대신 무작위 순서로 50번 돌려도(판정 제외) 연 -46 → -44% 다.
- 진입일 단위 Deflated Sharpe 는 6개 모두 0.000 이다. 진입일 샤프 자체가 음수(-0.19 → -0.82)다.

자세한 표는 `results/report.md`, 검증은 `results/checks.md` 에 생긴다(저장소에 올리지 않는다).

## 검증

지시서 5절의 6개 모두 통과했다.

1. 봉인: 모든 표의 마지막 날이 2026-09-23 이하.
2. 손 검산: S1·S2 거래 3건씩(단위 추가, 손절, 반대 돌파 청산)을 원래 가격으로 대조했다. N 은 따로 짠 반복문으로 다시 계산했다. 진입가, 추가가, 손절선, 청산가, 비용, 매도세율이 모두 맞는다.
3. S1 거르기: 건너뛴 신호 3건의 직전 가상 거래를 원래 가격으로 다시 걸어 보았다. 매수·매도일과 가격이 기록과 같고 모두 이익이었다.
4. 계좌 대조: 마지막 자산 = 처음 자산 + 거래 손익 합(차이 0원). 단위 수 최대 9(한도 12), 종목당 최대 4.
5. 마지막 20거래일 가격을 흔들어도 그 전에 끝난 거래가 하나도 바뀌지 않는다.
6. 무작위 진입의 종목은 모두 그날 살 수 있는 종목이고, 들고 있거나 그날 판 종목을 다시 사지 않았다.

## 돌리는 법

```
cd turtle_kr_backtest
pip install -r requirements.txt
python -m src.signals     # 종목별 배열과 후보 (1분 안팎)
python -m src.portfolio
python -m src.baseline    # 무작위 진입 400번 + 순서 민감도 100번, 6개 프로세스
python -m src.dsr
python -m src.metrics
python -m src.stress
python -m src.costs
python -m src.report
python -m src.checks
```

시세는 `../../krx_data`(환경변수 `KRX_DATA_DIR`)를 읽는다. 모든 값은 `config.yaml` 에 있다.
