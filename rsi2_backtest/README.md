# rsi2_backtest

래리 코너스의 RSI(2) 규칙을 QQQ 에 쓴 [tradeitsimplesolutions/TIS-RSI2-Research](https://github.com/tradeitsimplesolutions/TIS-RSI2-Research) 를 다시 돌리고, 원본에 없는 세 가지를 더한다. 같은 위험으로 맞춘 매수 보유와의 비교, 200일선 필터를 빼거나 뒤집었을 때의 결과, 1번 IBS 전략과 섞었을 때의 결과다.
엔진은 [krx_backtest_core](https://github.com/destory1984/krx_backtest_core) v0.2.1 을 그대로 쓰고, 이 폴더에는 규칙과 검증 코드만 둔다. 주문 코드, 증권사 API 연결은 없다.

## 규칙

- RSI(2): 와일더 방식. 종가 변화의 상승폭·하락폭을 `ewm(alpha=1/2, min_periods=2, adjust=False)` 로 평균낸다. 하락폭 평균이 0 이면 값이 없고 신호도 없다.
- 진입(원본): 보유하지 않은 상태에서 전날 종가 기준 RSI(2) < 15 이고 종가 > 200일선이면 오늘 시가에 산다.
- 청산(원본): 전날과 그 전날이 모두 양봉(종가 > 시가)이면 오늘 시가에 판다. 그 전날이 신호일이어도 센다(원본 코드와 같다).
- 롱 온리, 한 번에 한 포지션, 손절 없음, 최대 보유일 없음. 표본 끝에 열린 거래는 마지막 종가로 평가하고 표에 표시한다.
- 양봉은 조정 전 시가·종가로 가린다. 수정주가 계수의 반올림 때문에 시가 = 종가인 날(QQQ 31일)이 양봉이 되지 않게 하려는 것이다.

| 체결 | 진입 | 청산 |
|---|---|---|
| `open` (원본) | 신호 다음 날 시가 | 청산 조건 다음 날 시가 |
| `close` | 신호일 종가 | 청산 조건이 선 날 종가 (진입한 날에는 팔지 않는다) |

그리드는 돌리기 전에 고정했다. 종목 4(SPY, QQQ, IWM, DIA) × RSI(2) 문턱 3(5, 10, 15) × 추세 필터 3(200일선 위, 없음, 200일선 아래) × 청산 3(2연속 양봉, 종가 > 5일선, RSI(2) > 70) × 체결 2 = 216개 조합이다. 비용은 편도 0.12%(수수료 0.07% + 슬리피지 0.05%)이고, 원본 비용(편도 0.05%) 결과도 같이 낸다.

## 돌리는 법

미국 데이터는 저장소 밖 `../../us_data` 를 다른 백테스트와 같이 쓴다. `watchlist.txt` 에 SPY, QQQ, IWM, DIA 가 이미 있어 새로 받을 것이 없다.
단계 0 은 원본 저장소를 모음 저장소 밖에 받아 둔 것이 있어야 한다(`../../_ref/TIS-RSI2-Research`, 커밋 d5fb4c9). 원본 코드는 그 폴더에서만 돌리고 이 폴더로 복사하지 않는다(원본에 라이선스가 없다).

```
pip install -r requirements.txt
python ../../_ref/TIS-RSI2-Research/motor/rsi2_motor.py   # 원본 재실행, 원본 폴더의 resultados/ 를 다시 쓴다
python -m src.replicate      # 단계 0: 우리 반복문
python -m src.stage0 --export   # 단계 0: 원본 출력과 대조 (--export 는 원본 지표값을 한 번 뽑는다)
python -m src.port           # 단계 1: 엔진 대조, 청산 특이점
python -m src.grid           # 단계 2·3: 216개 조합 x 비용 2가지
python -m src.walkforward    # 단계 4
python -m src.mix            # 단계 5
python -m src.overfit        # 단계 6: Deflated Sharpe, 무작위 진입
python -m src.aftertax       # 단계 6: 세후
python -m src.report         # results/report.md (--readme 를 붙이면 이 README 의 결과 부분도 다시 쓴다)
python -m src.checks         # 검증 → results/checks.md
```

모든 파라미터는 `config.yaml` 에 있다.

## 한계

- 엔진 쪽 기간은 2008년부터다(us_data 가 2007년부터라 200일선이 찬 뒤). 1999년부터는 단계 0 의 원본 CSV 에서만 봤다.
- `close` 체결은 종가를 보고 그 종가에 사고파는 것이라 실제로는 종가 동시호가(MOC) 주문이 필요하다.
- Deflated Sharpe 의 판단값(결과를 보기 전에 정한 값)은 이 폴더 216개 조합의 일별 샤프 분산을 쓴다. 1번·2번 그리드의 조합별 샤프까지 모아 세 폴더 1,032개 시행 전체의 분산으로 다시 잡은 민감도 값은 open 0.132, close 0.062 로 더 낮다(둘 다 0.95 미달, `report.md` 8장 민감도 표).
- 환율은 1,350원/달러로 고정했다. 쉬는 현금에는 이자를 붙이지 않았다.
- 걸어가며 검증의 보유 비교는 해마다 고른 종목을 이어 붙인 것이라, 종목을 바꿀 때의 비용과 세금은 넣지 않았다.
