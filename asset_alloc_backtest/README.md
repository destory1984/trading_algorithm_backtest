# asset_alloc_backtest

미국 주식(SPY), 선진국 주식(EFA), 신흥국 주식(EEM), 장기 국채(TLT), 금(GLD) 5개 사이에서 한 달에 한 번 비중을 바꾸는 문헌 규칙 3개가, 같은 5개를 20% 씩 고정해 드는 것(EW5)보다 나은지 판정했다. 지시서는 [SPEC.md](SPEC.md) 다.
주문 코드, 증권사 API 연결은 없다.

## 규칙

| # | 규칙 | 출처 |
|---|---|---|
| A1 이중 모멘텀 | SPY 12개월 수익률 > 0 이면 SPY·EFA 중 강한 쪽 100%, 아니면 TLT 100% | Antonacci(2014), 채권 AGG → TLT |
| A2 10개월선 5자산 | 5종목 20% 씩, 10개월선 아래인 종목의 몫은 현금 | Faber(2007), IEF·VNQ·원자재 → TLT·EEM·GLD |
| A3 상위 2개 | 12개월 수익률 상위 2종목 50% 씩, 수익률 ≤ 0 이면 그 몫은 현금 | Faber(2010) + 절대 모멘텀 |

- 월말 종가로 정하고 다음 달 첫 거래일 시가에 비중을 맞춘다. 현금 수익은 0%(단기 국채 데이터가 없다).
- 배당 반영 가격, 편도 비용 0.12%. 기간 2008-05-01 → 2026-09-25.
- 이웃 값: A1·A3 9·15개월, A2 8·12개월.

## 결과

**판정: 3개 모두 탈락이다.** 세 규칙 모두 기준 2(샤프가 EW5 보다 0.10 이상 높다)를 넘지 못했다.

| 규칙 | 연 수익률 | 최대 낙폭 | 샤프 (EW5 대비) | 낙폭 맞춘 고정 비중 대비 | 비용 | 못 넘은 기준 |
|---|---|---|---|---|---|---|
| A1 이중 모멘텀 | +7.2% | -33.7% | 0.49 (-0.09) | +0.8%p | -0.48%p | 2 샤프, 3 낙폭, 4 후반, 5 이웃 |
| A2 10개월선 5자산 | +5.2% | -10.4% | 0.64 (+0.06) | +3.3%p | -0.26%p | 2 샤프 |
| A3 상위 2개 | +6.9% | -23.4% | 0.56 (-0.02) | +2.6%p | -0.51%p | 2 샤프, 5 이웃(9개월 낙폭 -28.6%) |
| EW5 (비교) | +7.1% | -37.2% | 0.58 | | -0.05%p | |
| SPY 보유 (비교) | +11.8% | -51.5% | 0.67 | | | |
| SPY 60 / TLT 40 (참고) | +8.5% | -29.9% | 0.78 | | -0.04%p | |

기준: (1) 낙폭을 맞춘 EW5 × k + 현금보다 수익 높음, (2) 샤프 ≥ EW5 + 0.10, (3) 최대 낙폭 ≤ SPY 의 50%, (4) 전반(2008-05 → 2016)·후반(2017 →) 각각 기준 1 과 수익 > 0, (5) 이웃 2개도 기준 1·3, (6) 비용 ≤ 연 1%p.

- **A2 가 가장 가까웠다.** 기준 6개 중 5개를 넘었다. 최대 낙폭을 EW5 의 -37% 에서 -10% 로 줄였고, 같은 낙폭이 되게 EW5 를 24% 만 드는 것보다 연 3.3%p 더 벌었다. 이웃 8·12개월도 같은 모양이다. 그러나 평균 34% 를 현금으로 두어 수익이 EW5 보다 1.9%p 낮고, 샤프 차이는 +0.06 으로 기준 +0.10 에 못 미쳤다.
- **A1 은 예상대로 2022 에 다쳤다.** 2008 에는 TLT 로 옮겨 금융위기 구간을 +15% 로 넘겼지만, 2022-06 에 SPY 에서 TLT 로 옮긴 뒤 채권 하락을 같이 맞아 그해 -24% 였다. 한 종목 100% 라 2020-03 은 SPY 와 같이 -34% 였다. 후반은 같은 낙폭의 EW5 보다 1.4%p 뒤졌다.
- **A3 는 수익과 낙폭이 EW5 와 SPY 사이다.** 낙폭 -23% 로 기준 3 을 넘었지만 9개월 이웃은 -28.6% 로 SPY 절반(-25.7%)을 넘었다.
- **단순 60/40 이 세 규칙 모두보다 샤프가 높다(0.78).** 판정 대상은 아니지만, 이 기간에는 SPY 와 TLT 두 개를 고정 비중으로 든 것이 5종목을 굴린 것보다 나았다. 5종목 가운데 EEM(신흥국)이 가장 약해 EW5 자체가 SPY 보다 수익이 4.7%p 낮다.
- **비용은 문제가 아니다.** 한 해 비중 변경은 1.5 → 7.3번, 비용으로 빠지는 수익은 연 0.24 → 0.61%p 다. 단기 규칙을 떨어뜨린 비용의 벽은 월간 배분에서는 없다.
- **현금 이자 민감도(연 1.8%, 판정 제외):** A2 를 기준대로 보면 샤프 차이가 +0.13 이 되어 "통과"로 나온다. 그러나 이는 기준 2 의 샤프가 현금 0% 기준이라, 현금을 많이 드는 A2 에 이자가 변동 없이 붙어서다. 이자를 뺀 초과 샤프로는 차이가 +0.05 다. A1·A3 는 판정이 그대로다.
- Deflated Sharpe(참고): EW5 를 넘는 월 수익으로 재면 9개 모두 0.25 이하다.

자세한 표는 `results/report.md`, 검증은 `results/checks.md` 에 생긴다(저장소에 올리지 않는다).

## 검증

지시서 6절의 5개 모두 통과했다: 봉인(마지막 날 2026-09-25), SPY 100% 계좌 = SPY 보유(차이 2e-14), 규칙마다 비중이 바뀐 달 3번 손 검산(원래 파일에서 월말 종가를 다른 방법으로 다시 뽑아 대조, 비용 = 회전율 × 0.12%), 비중은 월초에만 바뀜, 마지막 20거래일 가격을 흔들어도 그 전 결정이 바뀌지 않음.

## 돌리는 법

```
cd asset_alloc_backtest
pip install -r requirements.txt
python -m src.run
python -m src.metrics
python -m src.stress
python -m src.dsr
python -m src.report
python -m src.checks
```

데이터는 `../../us_data/prices/{SPY,EFA,EEM,TLT,GLD}.parquet`(야후, `adj_close` 포함)를 읽는다. 다른 곳에 있으면 환경변수 `US_DATA_DIR` 로 알려 준다. 모든 값은 `config.yaml` 에 있다.
