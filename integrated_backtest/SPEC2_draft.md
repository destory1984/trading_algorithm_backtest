# 밸류 리밸런싱 TQQQ 기록 장치 작업 지시서 (초안)

작성일 2026.9.29. 상태: 초안. 사용자가 "이대로 재가한다"고 하기 전에는 코드를 짜거나 데이터를 받지 않는다.
같은 폴더(`integrated_backtest`)에서 한다. 규칙 코드는 `src/us/strategies.py` 의 `value_rebalance` 를 바탕으로 한다. 지금 도는 변동성 목표 기록 장치(index_timing_backtest SPEC2, 작업 `vol_target_log`)는 건드리지 않는다.

## 1. 목적

integrated_backtest 에서 가장 가까웠던 U2 TQQQ(밸류 리밸런싱)를 **앞으로 쌓이는 데이터로만** 판정한다. 백테스트에서 이 규칙은 2010-02 → 2026-09 에 연 +15.9%, 최대 낙폭 -27.3% 로 같은 낙폭의 TQQQ 보유(비중 0.24)보다 연 3.1%p 높았고, 이웃(밴드 10·20%)과 비용 2배도 넘었다. 떨어진 것은 두 기간 기준 하나였다(앞 절반 2010 → 2018 에서 -5.3%p). 과거 자료로는 더 알 것이 없으므로 앞으로의 데이터로 본다.

- 한다: 시작 전 관문 백테스트 한 번, 매 거래일 뒤 데이터 받기, 갱신일에 목표와 주문 계산, 기록, 주문이 필요할 때 텔레그램 알림, 종이 계좌, 1년 점검과 2년 판정 보고서
- 하지 않는다: 주문, 증권사 API 연결, 규칙 값 바꾸기, 판정 기준 바꾸기, 유료 데이터

## 2. 규칙 (U2 기준선, 체결만 바꿈)

- 대상: TQQQ. 가격은 배당 반영(`시가 × adj_close / close`, 종가 = adj_close).
- 종이 계좌 10만 달러. 시작할 때 50% 를 TQQQ 로 사고 50% 는 현금 풀로 둔다. 목표 평가금 V 의 처음 값은 산 TQQQ 의 평가금이다.
- 시작 뒤 10거래일마다(갱신일) 종가로: V ← V × (1.10)^(10/252). TQQQ 평가금 E = 주식 수 × 종가.
  - E < V × 0.85 면 V - E 만큼 산다(풀 안에서).
  - E > V × 1.15 면 E - V 만큼 판다(판 돈은 풀로).
- **체결: 갱신일 종가로 판단하고 다음 거래일 시가에 산다·판다.** 백테스트는 갱신일 종가에 바로 체결했다. 그러나 종가를 본 뒤 그 종가에 체결할 수는 없어서, 기록 장치는 다음 날 시가로 바꾼다. 금액은 판단 때 정한 달러 금액이다(시가에 그 금액만큼 사거나 판다).
- 비용: 바뀐 금액의 편도 0.12%(수수료 0.07% + 슬리피지 0.05%). 풀은 현금 0%. 주식 수는 소수로 둔다.
- 참고(판정 제외): 밴드 10%, 20% 도 같은 방식으로 기록한다.

## 3. 시작 전 관문 (결과를 보기 전에 고정)

기록을 시작하기 전에 2절의 규칙(다음 날 시가 체결)으로 2010-02-11 → 2026-09-25 TQQQ 를 한 번 돌린다(`results/us/live_gate.md`).

- 이 판본이 전체 구간에서 같은 낙폭의 TQQQ 보유(w × TQQQ + 현금)보다 연 수익률이 높으면 기록을 시작한다.
- 낮으면 기록을 시작하지 않고 결과만 보고한다. 체결 방식 하나로 판정이 뒤집히는 규칙은 기록할 값어치가 적다.
- 앞·뒤 절반 결과도 같이 적되(참고), 관문은 전체 구간 하나로만 정한다. 이 관문은 이미 본 자료라서 "기록할지"만 정하고 판정에는 쓰지 않는다.

## 4. 데이터

- 기록 장치 전용 `../../live_data` 에 `python -m krxbt.fetch_us --dir ../../live_data --tickers TQQQ` 로 받는다. 이미 있는 SPY 파일과 따로라 변동성 목표 장치에 영향이 없다. 연구용 `us_data` 는 건드리지 않는다.
- 야후 데이터가 비거나 마지막 봉이 한국 날짜로 4일보다 오래되면 계산하지 않고 "데이터 실패"만 알린다(변동성 목표 장치와 같은 기준).
- 장중에 돌리면 야후가 끝나지 않은 오늘 봉을 준다. 뉴욕 시간 16:15 전이면 오늘 봉을 버린다(변동성 목표 장치와 같다).
- 휴장일은 변동성 목표 장치의 NYSE 달력 코드(성금요일, 준틴스 2022 → 등)를 복사해 쓴다.

## 5. 할 일

1. `src/us/live_gate.py`: 3절의 관문.
2. `src/us/live_vr.py` (매 실행)
   - TQQQ 받기 → 시작일부터 오늘까지 종이 계좌를 규칙 코드로 다시 계산한다(10거래일 세기, V, 주문).
   - `results/us/live/log.csv` 에 한 줄: 실행 시각, 마지막 봉, 종가, 오늘이 갱신일인지, V, E, 풀, 주문(있으면 금액과 방향), 자가 점검.
   - 갱신일에 주문이 생기면 텔레그램으로 알린다: "TQQQ 밸류 리밸런싱: 평가금 $X, 목표 $V(밴드 밖) → 다음 거래일(10-14) 시가에 $Y 매수, 풀 남은 돈 $Z". 환경변수 `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` 를 쓰고, 토큰이 든 주소가 오류·로그에 찍히지 않게 감싼다.
   - 매달 첫 실행에 종이 계좌 요약(시작 뒤 수익, 최대 낙폭, TQQQ 보유 대비, 풀 비율)을 한 번 보낸다.
   - 빠진 실행은 다음 실행이 채운다. 이미 알린 주문은 다시 알리지 않는다(`state.json`).
3. 자가 점검(매 실행): 기록된 갱신일·주문이 같은 데이터로 처음부터 다시 계산한 것과 같은지 본다. 다르면 알리고, 야후가 과거 가격을 고친 경우면 기록을 고치지 않고 차이를 `log.csv` 에 남긴다.
4. `src/us/live_report.py`: 종이 계좌와 TQQQ 보유 곡선, 1년 점검과 2년 판정 표(`results/us/live/report.md`).
5. 실행 등록: 윈도우 작업 스케줄러에 한국 시간 화 → 토 07:40 에 `python -m src.us.live_vr && python -m src.us.live_report` 를 돌리는 작업(이름 예: `vr_log`)을 **사용자가** 등록한다. README 에 명령을 적는다. 작업 등록과 텔레그램 발송 시험은 사용자가 하라고 할 때만 한다.

## 6. 시작

- 관문을 넘으면, 승인 뒤 첫 실행이 시작을 정한다. 종이 계좌는 그 실행 뒤 첫 NYSE 시가에 50% 를 산다. 그날이 0번째 거래일이고, 10·20·30 … 번째 거래일 종가가 갱신일이다.
- 시작 기록(시작일, 처음 V, 처음 주식 수)을 `state.json` 과 README 에 적는다.

## 7. 판정 기준 (지금 고정)

**1년(252거래일) 점검은 보고만 한다.** 갱신일이 25번뿐이라 판정하기에 짧다.

**2년(504거래일) 판정.** 아래를 모두 만족하면 "따라 할 만하다"로 올린다.

1. **공짜가 아님**: 종이 계좌 연 수익률이 같은 기간 같은 낙폭의 TQQQ 보유(w × TQQQ + 현금, 매일 맞춤)보다 높다
2. **낙폭**: 종이 계좌 최대 낙폭이 같은 기간 TQQQ 보유 최대 낙폭의 50% 이하(백테스트 비율은 33%)
3. **실행**: 주문이 생긴 갱신일마다 알림이 다음 거래일 시가 전에 갔다(빠진 알림 0건)
4. **일치**: 자가 점검 불일치가 야후의 과거 가격 수정 말고는 0건

그 2년 동안 TQQQ 보유의 최대 낙폭이 -20% 보다 얕으면 기준 1·2 는 판정을 1년 미룬다. 낙폭을 줄일 기회가 없었으므로 이 규칙의 값어치를 볼 수 없다.

## 8. 시행 수

기록은 이미 판정한 규칙의 앞날을 보는 것이라 새 시행으로 세지 않는다(변동성 목표 기록 장치와 같다). 관문 백테스트는 체결을 바꾼 판본 1개라 미국 누적에 1 을 더한다(1,268 → 1,269).

## 9. 하지 말 것

- 주문, 증권사 API 연결
- 규칙 값(50% 시작, 연 10% 성장, 10거래일, 밴드 15%, 다음 날 시가 체결) 바꾸기. 바꾸고 싶으면 기록을 멈추고 새 지시서를 쓴다
- 판정 기준을 기록을 본 뒤 바꾸기, 관문 결과를 보고 규칙을 고쳐 다시 관문에 넣기
- 연구용 `us_data` 에 받기, 변동성 목표 장치의 파일·작업 고치기
- 토큰, 대화방 번호를 코드·로그·저장소에 넣기

## 10. 예상에 대한 메모

- 관문: 종가 → 다음 날 시가로 하루 늦추면, TQQQ 처럼 하루 변동이 큰 종목에서는 체결가가 판단가와 몇 % 씩 달라진다. 다만 2주에 한 번 밴드를 벗어날 때만 거래하므로(백테스트에서 한 해 몇 번), 전체 판정은 크게 바뀌지 않을 것으로 본다. 관문은 넘을 것 같다.
- 2년 판정: TQQQ 가 계속 오르면 풀 절반이 현금으로 남아 보유보다 훨씬 덜 번다. 그래도 기준 1 은 같은 낙폭의 보유(비중 0.2 → 0.3 안팎)와 비교하므로 넘을 수 있다. 큰 하락이 오면 풀로 사들이는 규칙이라 기준 2 가 드러난다. 하락이 너무 깊고 길면(2000 → 2002 같은) 풀이 바닥나 낙폭이 커진다.
- 원화·세금: 종이 계좌는 달러 기준이고 환율, 양도세(연 250만 원 넘는 이익 22%)는 넣지 않는다. 실제로 따라 한다면 이 둘이 결과를 바꾼다.

예상이 맞든 틀리든 기준은 바꾸지 않는다.
