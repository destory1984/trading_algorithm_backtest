# integrated_backtest

사용자가 준 통합 설계서([ORIGINAL_SPEC.md](ORIGINAL_SPEC.md))에서 이 저장소가 아직 판정하지 않은 전략 8개를 골라, 결과를 보기 전에 판정 기준을 붙인 지시서([SPEC.md](SPEC.md))대로 돌렸다. 이미 판정한 BNF, 터틀, 옛 GEM 은 다시 돌리지 않고 통합 비교에만 가져왔다. 분봉(ORB)과 DART 재무 조건은 이번 범위에서 뺐다.
주문 코드, 증권사 API 연결은 없다.

## 전략과 판정 대상

| ID | 전략 | 시장 | 판정 대상(원전 기준 조합) |
|---|---|---|---|
| A2 | 코너스 RSI(2) | 한국 개별주 | 종가 > MA200 이고 RSI(2) ≤ 10 → 다음 날 시가, 종가 > MA5 면 다음 날 시가 청산, 최대 10일 |
| B-O | 추세 추종, 오닐 기준 | 한국 개별주 | 종가 > 60일 최고가, 거래대금 20일 평균의 1.4배 이상, RS ≥ 80, 지수 120일선 위. 손절 -7%, 종가 < MA20 청산, 최대 60일 |
| B-M | 추세 추종, 미너비니 템플릿 | 한국 개별주 | B-O 와 같고 RS 필터 대신 트렌드 템플릿 |
| C | 래리 윌리엄스 변동성 돌파 | 한국, 거래대금 상위 200 | 목표가 = 시가 + 전날 폭 × 0.5, 다음 날 시가 청산 |
| U1 | 무한매수법(기준선) | TQQQ, SOXL | 40분할, 목표 10%·12% |
| U2 | 밸류 리밸런싱(기준선) | TQQQ, SOXL | 50% 로 시작, 2주마다 목표 연 10% 성장, 밴드 15% |
| U3-G | 듀얼 모멘텀 원형(GEM) | SPY, EFA, AGG, BIL | 12개월 |
| U3-A | 가속형 듀얼 모멘텀 | SPY, SCZ, TLT | 1·3·6개월 평균 |

- 한국: 코스피·코스닥(상장폐지 포함) 2015-01 → 2026-09-23, 1억 원, 5자리, 종목당 자본의 20%. 수수료 0.015%, 슬리피지 0.1%(C 0.2%), 그해 매도세.
- 미국: 수수료 0.07% + 슬리피지 0.05%, 자산마다 첫날 → 2026-09-25.
- 새로 받은 자료: SCZ, AGG, BIL, 1999 년부터 QQQ(저장소 밖 `hist_data`).

## 결과

**판정: 10줄(전략 8개, U1·U2 는 종목 2개씩) 모두 탈락이다.**

| 전략 | 연 수익률 | 최대 낙폭 | 비교 기준 대비 | 못 넘은 기준 |
|---|---|---|---|---|
| A2 코너스 RSI(2) | -0.7% | -74.8% | -14.3%p | 1, 3, 4, 5 |
| B-O 오닐 | -5.1% | -75.2% | -18.7%p | 모두 |
| B-M 미너비니 | +13.2% | -76.1% | -0.5%p | 1, 3, 4, 5, 6 |
| C 변동성 돌파 | -37.6% | -99.7% | -51.2%p | 모두 |
| U1 TQQQ | +30.0% | -79.7% | -12.0%p | 모두 |
| U1 SOXL | +32.3% | -85.0% | -8.0%p | 1, 2, 3, 4 |
| U2 TQQQ | +15.9% | -27.3% | +3.1%p | 2 |
| U2 SOXL | +18.8% | -42.2% | -1.7%p | 1, 2, 3, 4 |
| U3-G GEM | +7.6% | -33.7% | +0.05%p | 2, 3, 4 |
| U3-A 가속 | +11.9% | -36.6% | +2.5%p | 2 |

비교 기준: 한국은 낙폭을 맞춘 코스피(총수익 근사), U1·U2 는 낙폭을 맞춘 같은 ETF 보유, U3 는 낙폭을 맞춘 SPY 보유. 한국 기준은 (1) 진입일 Deflated Sharpe ≥ 0.95 (시행 수 3,284), (2) 무작위 진입 200번의 95 백분위 이상, (3) 전체·학습·검증 모두 비교 기준보다 높음, (4) 이웃 3분의 2, (5) 슬리피지 2배, (6) 상위 5일을 빼도 거래당 평균 > 0. 미국 기준은 (1) 비교 기준, (2) 앞·뒤 두 기간, (3) 이웃, (4) 비용 2배, (5) U1 TQQQ 는 합성 1999 → 2010.

### 한국

- **C(변동성 돌파)는 비용에 진다.** 거래대금 상위 200 종목에서도 하루에 사고파는 왕복 비용(슬리피지 0.4% + 수수료 + 매도세, 0.6% 안팎)을 이기지 못한다. 그리드 32칸 모두 거래당 평균이 음수다(가장 좋은 칸 -0.29%). 1억 원이 11년 동안 0.4% 가 됐다.
- **A2(RSI2)는 고르는 힘은 있지만 비용이 먹는다.** 같은 청산 규칙으로 무작위 종목을 산 200번(중앙값 연 -18.2%)보다 훨씬 낫고(100% 위치), 거래 단위로도 승률 58%, 거래당 +0.16% 다. 그러나 한 해 260번 넘게 사고팔아 왕복 비용 0.4 → 0.5% 가 이익을 거의 다 먹는다. 슬리피지를 0.2% 로 올리면 연 -10.7% 다. 학습기(2015 → 2020)는 연 +13.1% 였지만 검증기(2021 →)는 -13.3% 였다. 오래 거래정지된 뒤 정리매매에서 -93%, -95% 로 끝난 거래가 2건 들어 있다.
- **B-M(미너비니 템플릿)이 가장 가까웠다.** 연 +13.2% 로 무작위 진입(중앙값 -8.8%, 95 백분위 -1.6%)을 크게 이겼다. 그러나 최대 낙폭 -76% 라서, 같은 낙폭이 되게 맞춘 코스피(w = 1, 코스피 자체)보다 연 0.5%p 낮다. 학습기 -0.3%, 검증기 +29.2% 다. 해마다 보면 2019 +45%, 2020 +89%, 2024 +75%, 2025 +233% 에 이익이 몰렸고, 2016 -43%, 2021 -35% 처럼 크게 잃은 해도 있다. 이웃 4칸 중 1칸만 기준 3 을 넘었고, 슬리피지 2배에서 연 +9.1% 로 떨어진다.
- **B-O(오닐 기준)는 무작위를 넘지 못했다**(78% 위치). 터틀에서 본 "돌파 뒤 되밀림"과 같은 방향이다. B 그리드 540칸을 묶어 보면 필터 없음 -1.25%, RS80 -0.57%, 템플릿 -0.24% 로, 템플릿과 지수 국면 필터가 손실을 줄인다. 거래당 평균이 0 보다 큰 칸은 540칸 중 113칸이다.
- 4개 모두 진입일 Deflated Sharpe 가 0.000 이다. 진입일 샤프가 -0.48 → +0.02 로, 시행 수 3,284 에서 기대 최대(0.19 → 0.33)에 한참 못 미친다.

### 미국

- **U1(무한매수법)은 레버리지 ETF 를 그냥 들고 있는 것보다 못하다.** TQQQ 연 +30.0% 로 좋아 보이지만 최대 낙폭 -79.7% 가 보유(-81.7%)와 비슷하고, 같은 낙폭의 보유는 연 +42.0% 였다. 회차 소진이 TQQQ 18번, SOXL 16번 있었고, 회복에 가장 길게 604·679거래일이 걸렸다. 합성 구간(1999 → 2010)은 합성 보유와 함께 -99% 대로 무너졌다.
- **U2 TQQQ(밸류 리밸런싱)가 가장 가까웠다.** 연 +15.9%, 최대 낙폭 -27.3% 로 같은 낙폭의 TQQQ 보유(w 0.24)보다 연 3.1%p 높고, 밴드 10·20% 이웃과 비용 2배도 넘었다. 떨어진 것은 두 기간 기준 하나다. 앞 절반(2010-02 → 2018-06)에서 그 기간 낙폭에 맞춘 보유보다 5.3%p 낮았다. SOXL 에서는 이기지 못했다.
- **U3-A(가속형)도 두 기간 하나로 떨어졌다.** 전체로는 같은 낙폭의 SPY 보다 연 2.5%p 높지만, 이익이 앞 절반(2008 → 2017, +10.2%p)에 몰렸고 뒤 절반은 -5.8%p 다. U3-G(원형 GEM)는 전체 +0.05%p 로 거의 같고, 뒤 절반 -6.7%p, 이웃 9·15개월도 넘지 못했다.
- **합성 3배 QQQ 는 실제 TQQQ 보다 연 5.9%p 높게 나온다**(검증 7 의 한도 2%p 초과). 원문의 합성식(3배 수익 - 연 0.95%)에는 3배를 만드는 차입 비용이 없어서다. 그래서 U1 합성 구간 결과는 "합성 오차 큼"으로 적는다. 합성 쪽이 유리하게 나오는 오차인데도 기준을 넘지 못했다.

### 통합 비교 (판정 없음, 2015-01 → 2026-09)

- 샤프 순위: U2 SOXL 0.86, U2 TQQQ 0.85, 기존 미국 T3 변동성 목표 0.84, U1 SOXL 0.83, SPY 0.83 … 코스피 총수익 0.69, bnf 동반급락 0.61, B-M 0.52, A2 0.16, B-O 0.10, C -2.65.
- 상관: 미국 전략끼리는 0.5 → 0.97 로 높고(모두 결국 미국 주식), 한국 개별주 전략과 미국 전략은 0.1 → 0.3 이다. bnf 동반급락은 거의 모든 전략과 0.0 → 0.3 이다.
- 국면: B-M 은 코스피가 120일선 위이고 변동성이 큰 달에 월 +8.7% 를 벌고, 120일선 아래·저변동 달에 -2.7% 를 잃는다. A2 는 반대로 상승·고변동 달에 -3.0% 다. 추세 추종과 평균 회귀가 서로 다른 국면에서 번다는 원문의 가설과 맞는 모양이다.
- 섞기: B-M + bnf 동반급락 + 미국 T3 변동성 목표를 1/3 씩 섞으면 연 +13.7%, 월말 기준 최대 낙폭 -26% 로, 구성 낙폭 평균(-37%)보다 얕다. 다만 섞은 셋 모두 판정에서 떨어진 규칙이고, 이 조합은 결과를 보고 고른 것이다.
- 학습·검증: 그리드의 거래당 평균 순위는 두 기간이 비슷하다(A2 0.97, B 0.88, C 0.80). 지형은 안정적이지만 대부분 음수 쪽에서 안정적이다. 전략 16개의 연 수익률 순위 상관은 0.36 이다.

자세한 표는 `results/report.md`, 검증은 `results/checks.md`, 그림은 `results/compare/` 에 생긴다(저장소에 올리지 않는다).

## 검증

지시서 8절의 7개 모두 통과했다.

1. 봉인: 한국 2026-09-23, 미국 2026-09-25 뒤 날짜 없음.
2. 미래 데이터 금지: 한국 표본 101종목(무작위 100 + 삼성전자)에서 마지막 20거래일 가격을 흔들어도, 그 전에 끝난 거래 68만 건이 하나도 바뀌지 않는다. 미국 전략 6개의 곡선도 그대로다.
3. 손 검산: 한국 전략마다 거래 3건(청산선, 손절, 최대 보유)을 원래 가격으로 대조했다. 신호 조건(RSI2, MA200, 60일 최고가, 거래대금 배수, 목표가), 체결가, 비용, 매도세율이 모두 맞는다.
4. 수정주가·끊김: 그리드 거래 1,265만 건 중 시세 끊김으로 뺀 것 5만 1,591건. 판정 포트폴리오 거래에서 가격 제한을 넘는 움직임은 정리매매 3건뿐이다.
5. 상장폐지 종목의 마지막 날에 끝난 거래는 모두 강제 청산으로 기록됐다(1,107건). 거래정지일 체결 0건.
6. U1: 매수·매도 기록 4,269줄로 보유와 평단을 다시 쌓아 맞춰 보았다. 불일치 0건, 사이클 93개.
7. 합성 3배 QQQ 와 실제 TQQQ 의 차이 연 5.9%p(한도 2%p 초과, 결과에 적음).

## 돌리는 법

```
cd integrated_backtest
pip install -r requirements.txt
python -m src.us.fetch        # SCZ, AGG, BIL, QQQ(1999 →) 한 번만
python -m src.kr.build        # 한국 종목별 계산, 6개 프로세스 (5분 안팎)
python -m src.kr.evaluate     # 포트폴리오, 무작위 진입 800번, 판정
python -m src.us.evaluate
python -m src.compare
python -m src.report
python -m src.checks
```

시세는 `../../krx_data`, `../../us_data`, `../../hist_data`(환경변수 `KRX_DATA_DIR`, `US_DATA_DIR`, `HIST_DATA_DIR`)를 읽는다. 모든 값은 `config.yaml` 에 있다.
