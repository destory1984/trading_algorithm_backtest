# vol_target_history

index_timing_backtest 의 미국 T3(변동성 목표 15%)를 이 저장소가 한 번도 쓰지 않은 1928 → 2006 S&P 500 지수(^GSPC)에 그대로 돌려, 2008 → 2026 과 같은 기준으로 판정했다. 지시서는 [SPEC.md](SPEC.md) 다.
주문 코드, 증권사 API 연결은 없다. 2026-09-29 부터 도는 T3 기록 장치(index_timing SPEC2)와는 따로이고, 그 장치는 바꾸지 않았다.

## 규칙과 조건

- 비중 = min(1, 15% / 지난 20거래일 연환산 변동성). 매주 마지막 거래일 종가로 계산하고, 지금 목표와 10%p 넘게 다를 때만 바꾼다. 이웃 12%·18%. index_timing 과 같은 값이다.
- 1962년 전에는 시가가 없어서 **다음 날 종가**에 사고판다(index_timing 은 다음 날 시가). 2008 → 2026 SPY 에서 이 차이는 연 +0.14%p, 낙폭 -30.3% → -29.8% 로 작다.
- ^GSPC 는 배당이 빠진 가격 지수라 연 4% 배당을 달력 날짜로 더한 근사로 판정했다. 현금은 0%. 편도 비용 0.12%.
- 곡선 1928-02-01 → 2006-12-29. 기준 4 의 시대: 1928 → 1949, 1950 → 1969, 1970 → 1989, 1990 → 2006.

## 결과

**판정: 탈락이다(기준 1, 5).** 최대 낙폭이 보유의 71.0% 로 한도 70% 를 1.0%p 넘었고, 이웃 18% 는 76.6% 였다.

| 기준 | 결과 | 내용 |
|---|---|---|
| 1 낙폭 ≤ 보유 70% | X | -60.1% 대 -84.7%, 71.0% |
| 2 수익이 보유보다 1.5%p 넘게 낮지 않음 | O | +9.0% 대 +10.0%, -1.0%p |
| 3 낙폭 맞춘 고정 비중보다 수익 높음 | O | 지수 52% + 현금 대비 +3.4%p |
| 4 시대 4개 모두 낙폭 얕고 수익 -3%p 이내 | O | 수익 차이 -0.6, -0.8, -0.6, -2.3%p |
| 5 이웃 12%·18% 모두 기준 1·3 | X | 12% 는 63.0%, 18% 는 76.6% |
| 6 한 해 거래 12번 이하 | O | 5.5번 |

- **낙폭을 줄인 것은 대공황뿐이다.** 1929 → 32 는 변동성이 먼저 커져 평균 비중 49% 로 -85% 를 -59% 로 줄였고, 1937 → 38 도 -53% → -33% 였다. 그 밖의 큰 하락 8개에서는 2.6 → 8.7%p 만 얕았다. 1987 폭락은 -33% → -28%, 2000 → 02 닷컴 하락은 -45% → -42% 였다. 1987 은 금요일(10-16) 종가로 비중을 0.81 → 0.52 로 줄이기로 했지만, 다음 날 종가에 실행하는 탓에 월요일 폭락을 0.81 로 맞고 그날 종가에 팔았다.
- **최대 낙폭 -60% 는 폭락이 아니라 긴 하락에서 나왔다.** 1930-04 고점에서 1942-04 까지 12년에 걸친 것이다. 변동성이 낮아진 뒤 비중을 다시 높였다가 1937 → 42 의 하락을 맞았다.
- **79년 전체로는 "지수 88% 를 늘 들고 있기"와 수익이 같다.** 평균 비중을 맞춘 고정 비중보다 연 +0.1%p 다. 차이는 낙폭이다. 같은 낙폭이 되게 지수를 52% 만 드는 것보다는 연 3.4%p 더 벌었다. 샤프는 0.71 로 보유(0.60)보다 높다.
- **1990 → 2006 에서는 같은 낙폭의 고정 비중에도 졌다(-1.3%p).** 1998 구간 평균 비중이 68% 라 그 뒤 반등을 덜 탔고(+6.0% 대 +13.9%), 2000 → 02 하락은 천천히 내려가 비중을 평균 74% 로만 낮췄다(낙폭 -45% → -42%).
- **2008 → 2026 과 비교:** 그 구간 낙폭 비율은 58% 였다. 2008 금융위기가 대공황처럼 변동성이 먼저 커진 하락이었기 때문이다. 79년으로 넓히면 그런 하락은 1929 와 1937 정도라서 비율이 71% 가 된다.

### 가정 민감도 (판정 제외)

| 가정 | T3 수익 / 보유 | 낙폭 비율 | 기준대로 보면 |
|---|---|---|---|
| 본(배당 4%, 현금 0%) | +9.0% / +10.0% | 71.0% | 탈락 (1, 5) |
| 배당 0% | +5.3% / +5.7% | 81.3% | 탈락 (1, 5) |
| 현금 3.8% | +9.4% / +10.0% | 67.8% | 탈락 (5) |

기준 2·3 은 세 가정에서 같다. 기준 1 은 현금에 이자를 주면 넘는다(현금으로 있는 몫이 대공황 동안 이자를 받아 낙폭이 얕아진다). 이웃 18% 는 어느 가정에서도 기준 1 을 넘지 못해 판정은 가정과 상관없이 탈락이다.

자세한 표는 `results/report.md`, 검증은 `results/checks.md`, 데이터 점검은 `results/data_check.md` 에 생긴다(저장소에 올리지 않는다).

## 검증

지시서 5절의 5개 모두 통과했다.

1. 봉인: 받은 파일부터 2006-12-29 까지뿐이다(2007-01-01 전까지만 요청했다).
2. 재현: 이 폴더 코드로 SPY 2008 → 2026 을 다음 날 시가로 돌리면 index_timing 의 보유·T3 3개와 연 수익률, 최대 낙폭, 거래 횟수가 모두 같다.
3. 데이터: 하루 ±10% 넘게 움직인 9일이 모두 알려진 날이다(1929-10-28·29·30, 1931-06-22, 1931-10-06, 1932-09-21, 1933-03-15, 1939-09-05, 1987-10-19).
4. 손 검산: 비중이 바뀐 3번을 원래 종가로 대조했다. 19,814일 모든 날의 수익을 비중을 따라가며 다시 계산해 기록과의 최대 차이가 5e-16 이다.
5. 마지막 20거래일 종가를 흔들어도 그 전 비중이 바뀌지 않는다. 비중은 주의 마지막 거래일 다음 날에만 바뀐다.

야후 ^GSPC 에는 1952년 전 토요일 장이 들어 있지 않다(토요일 행 0개). 그래서 지시서 2.4 의 토요일 걱정은 해당이 없다. 1968년이 226거래일인 것은 그해 서류 처리 적체로 수요일에 쉰 날들이다.

## 돌리는 법

```
cd vol_target_history
pip install -r requirements.txt
python -m src.fetch        # 한 번만. 파일이 있으면 멈춘다
python -m src.data_check
python -m src.run
python -m src.metrics
python -m src.stress
python -m src.report
python -m src.checks
```

^GSPC 는 저장소 밖 `../../hist_data/GSPC.parquet` 에 받는다(환경변수 `HIST_DATA_DIR` 로 바꿀 수 있다). 검증 2 는 `../../us_data/prices/SPY.parquet` 와 `../index_timing_backtest/results/metrics.csv` 가 있어야 한다. 모든 값은 `config.yaml` 에 있다.
