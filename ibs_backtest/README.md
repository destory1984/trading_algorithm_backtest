# ibs_backtest

SPY 의 IBS 평균회귀 규칙([toniker10/SPY-IBS-Mean-Reversion-Strategy](https://github.com/toniker10/SPY-IBS-Mean-Reversion-Strategy))을 비용, 체결 시점, 표본 밖 검증을 넣어 다시 돌린다.
엔진은 [krx_backtest_core](https://github.com/destory1984/krx_backtest_core) v0.2.1 을 쓰고, 이 저장소에는 규칙과 검증만 둔다. 주문 코드는 없다.

## 규칙

- IBS = (종가 - 저가) / (고가 - 저가). 고가 = 저가인 날은 0.5 (2007년 이후 네 ETF, 1993년 이후 SPY 모두 0일).
- 보유하지 않은 상태에서 IBS < 0.20 이면 진입, 보유 중 IBS > 0.80 이면 청산. 손절 없음, 롱 온리, 한 번에 한 포지션.
- 가격은 배당 반영 수정주가. 보유하지 않는 날은 현금이고 수익 0.

체결은 두 가지를 나란히 본다.

| 이름 | 진입 | 청산 |
|---|---|---|
| `close` | 신호일 종가 | 청산 신호일 종가 |
| `open` | 신호 다음 날 시가 | 청산 신호 다음 날 시가 |

원본 README 는 "다음 날 시가에 산다"고 적었지만, 코드(`position.shift(1) * Close.pct_change()`)는 `close` 와 같다.

## 결과 (2026-09-25 까지, 비용 편도 0.12%)

| | 연 수익률 | 최대 낙폭 | 샤프 |
|---|---|---|---|
| 원본 README (SPY 1993~, 비용 0) | +12.7% | -26.1% | 0.97 |
| 재현 `close`, 비용 0 | +12.5% | -26.1% | 0.96 |
| 재현 `close`, 비용 포함 | +4.9% | -29.0% | 0.43 |
| 재현 `open`, 비용 포함 | +3.4% | -33.0% | 0.32 |
| 걸어가며 검증 2011~, `close` | +3.6% | -20.6% | 0.42 |
| 걸어가며 검증 2011~, `open` | +3.4% | -20.1% | 0.37 |
| SPY 보유 2011~ | +14.2% | -33.7% | 0.87 |

- 원본 수치는 비용 0 에서 재현된다(거래 989건, 낙폭 같음). 한 해 29번 사고팔아서 편도 0.12% 비용을 넣으면 연 수익률이 12.5% 에서 4.9% 로 떨어진다.
- 다음 날 시가에 사고팔면 비용 0 에서도 연 1.5%p 줄어든다. 반등의 일부가 밤사이에 난다.
- 768개 조합 그리드(종목 4 × 진입 4 × 청산 4 × 체결 2 × 추세 필터 2 × 최대 보유일 3)에서 비용 포함 연 수익률이 SPY 보유(2008~ 연 11.3%)를 넘는 조합은 1개다.
- 해마다 과거만 보고 샤프 1등 조합을 골라 다음 해에 쓰면 연 3.4~3.6%, 샤프 0.37~0.42 로 SPY 보유(0.87)의 절반이다. 낙폭만 작다.
- 변동성 목표 사이징은 목표 10% 에서만 낙폭이 줄었고(-20.6% → -16.5%), 샤프는 목표 10/15/20% 모두 늘 100% 보다 낮았다.
- 미리 정한 기준(표본 밖 샤프 > SPY, 낙폭 < SPY, 손익분기 비용 ≥ 편도 10bp) 가운데 낙폭 하나만 만족한다. **신호 알림 후보로 올리지 않는다.**

자세한 표는 `results/report.md`, 검증은 `results/checks.md` 에 생긴다(저장소에는 올리지 않는다).

## 쉬는 날 SPY 들고 있기

걸어가며 검증(2011~)이 고른 조합의 거래를 그대로 두고, 쉬는 날 현금 대신 평가금액의 w 만큼 SPY 를 들고 나머지는 현금으로 둔다. 신호가 나면 전액을 신호 종목에 넣는다.
`all` 변형은 이번 실행에서 `close` 와 값이 완전히 같아 표에서 뺐다.

배당 반영 SPY 가격을 쓰므로 위 표 전부(IBS + SPY 대기, "SPY w% + 현금 고정", "SPY 보유")에 배당이 들어 있다.

"SPY w% + 현금 고정" 줄은 첫날 산 뒤 다시 맞추지 않아서, SPY 가 오르는 동안 비중이 계속 커진다. w = 0.5 / 0.7 / 0.8 / 0.9 로 시작한 네 줄의 실제 평균 SPY 비중은 70.9% / 84.5% / 90.2% / 95.3% 다.
반면 IBS + SPY 대기 줄의 평균 노출(평균 SPY 비중 + 평균 ETF 비중)은 훨씬 낮다: close 는 w = 0.5/0.7/0.8/0.9 에서 58.1%/74.9%/83.3%/91.7%, open 은 65.2%/79.2%/86.1%/93.1% 다. w 값만 보지 말고 이 평균 노출로도 비교해야 한다.

결과: 8개 IBS + SPY 대기 줄(close, open × w = 0.5/0.7/0.8/0.9) 가운데 같은 w 의 "SPY w% + 현금 고정" 줄을 연 수익률에서 이긴 줄은 없고, 샤프에서 이긴 줄도 없다. 예를 들어 open, w = 0.9 는 연 +10.3%·샤프 0.67 로, SPY 90% + 현금 고정의 연 +13.5%·샤프 0.86 보다 둘 다 낮다.

## 돌리는 법

미국 데이터는 저장소 밖 `../../us_data` 를 다른 알고리즘과 같이 쓴다. `us_data/watchlist.txt` 에 SPY, QQQ, IWM, DIA 가 있어야 한다.

```
pip install -r requirements.txt
python -m krxbt.fetch_us --dir ../../us_data   # 데이터 갱신, 약 3분
python -m src.replicate     # 단계 0: 원본 재현 (SPY 1993~ 를 yfinance 로 따로 받는다)
python -m src.grid          # 단계 2: 768개 조합, 약 2분
python -m src.checks        # 엔진 대조와 검증 → results/checks.md
python -m src.walkforward   # 단계 3
python -m src.park          # 쉬는 날 SPY 들고 있기
python -m src.volsize       # 단계 4
python -m src.report        # results/report.md
```

모든 파라미터는 `config.yaml` 에 있다. 그리드 값은 돌리기 전에 고정했고 결과를 보고 바꾸지 않았다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `SPEC.md` | 작업 지시서 원문 (단계, 그리드, 판단 기준) |
| `NOTES.md` | 판단과 이유, 검증 방법, 인수인계 |
| `src/replicate.py` | 원본 코드 방식을 단순 반복문으로 다시 짠 것. 엔진과 대조하는 기준 |
| `src/strategy.py` | IBS 규칙을 krxbt 엔진 배열(`cand`, `target`)로 만든다 |
| `src/grid.py` | 조합별 거래, 자산곡선(`run_portfolio(slots=1)`), 통계, 손익분기 비용 |
| `src/walkforward.py` | 해마다 과거만 보고 조합을 골라 다음 해에 쓴다 |
| `src/park.py` | 쉬는 날 SPY 를 비중 w 만큼 들고 대기 |
| `src/volsize.py` | 변동성 목표 비중 |
| `src/checks.py` | 엔진 대조, 미래 데이터, 진입일, 자산곡선 계산, 고가 = 저가인 날, 지수 대기 검증 |
| `src/report.py` | csv 를 읽어 보고서를 만든다 |

## 한계

- 미국 데이터가 2007년부터라 엔진 쪽 기간은 2008년부터다. 1993년부터는 단계 0 에서만 봤다.
- `close` 체결은 종가를 보고 그 종가에 사는 것이라 실제로는 종가 동시호가(MOC) 주문이 필요하다. 국내 증권사에서 되는지는 확인하지 않았다.
- 최대 보유일에 걸리면 `open` 방식이어도 그날 종가에 판다(엔진 규칙).
- 양도세(22%)는 넣지 않았다.
